# Explaining Reinforcement Learning Decisions in Self-adaptive Systems
# 解释自适应系统中的强化学习决策

Reinforcement Learning (RL) has been extensively used in autonomous and self-* systems, but RL policies, especially deep RL ones relying on neural networks, lack transparency and are difficult to understand. This can lead to diminished user trust, and makes for a more challenging verification of systems.

强化学习（RL）已被广泛应用于自主和自适应（self-*）系统中，但强化学习策略，尤其是依赖神经网络的深度强化学习策略，缺乏透明度且难以理解。这可能导致用户信任度降低，并使系统验证变得更具挑战性。

To address this challenge, this paper introduces Explanations using Alternative Realities for Reinforcement Learning (EARL), a Python library to produce counterfactual explanations in RL settings. This library allows the user to produce explanations by exploring What-if scenarios to clarify agent behavior by comparing possible outcomes.

为了应对这一挑战，本文介绍了“强化学习的替代现实解释”（EARL），这是一个用于在强化学习环境中生成反事实解释的 Python 库。该库允许用户通过探索“假设”（What-if）场景，并对比各种可能的结果，从而阐明智能体的行为。

Counterfactual explanations have been shown to be intuitive and user-friendly in psychology research, but have only recently been explored in RL, with existing implementations usually limited to toy examples and benchmarks. EARL supports counterfactual explanation generation in realistic RL-based self-adaptive systems.

心理学研究表明，反事实解释直观且对用户友好，但直到最近才被引入强化学习领域，且现有的实现通常仅限于简单的示例和基准测试。EARL 支持在真实的基于强化学习的自适应系统中生成反事实解释。

To demonstrate its applicability, we demonstrate its use in a simulation of CitiBikes, a self-adaptive bike-sharing system, and we provide evaluations showing how it performs in real applications.

为了证明其适用性，我们在 CitiBikes（一个自适应共享单车系统）的模拟中展示了该库的使用，并提供了评估结果，展示了其在实际应用中的表现。
