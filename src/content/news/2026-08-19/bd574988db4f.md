### Delphi Tools es el complemento para las Dev Tools
### Delphi Tools 是 Dev Tools 的绝佳补充

Días después de publicar las Dev Tools me topé con Delphi Tools. Una web similar pero con varios puntos diferentes que terminan siendo el complemento ideal.
在发布 Dev Tools 几天后，我发现了 Delphi Tools。这是一个类似的网站，但它有几个不同的亮点，最终成为了理想的补充工具。

En general, todos estos sitios ofrecen una base de características similares. Entonces lo bueno viene siendo cuando se tienen todo al alcance para tener un repertorio más grande de herramientas para complementar nuestro trabajo.
总的来说，所有这些网站提供的基础功能都很相似。因此，当我们将它们全部整合在一起时，就能拥有更丰富的工具库来辅助我们的工作，这才是最棒的地方。

Una de las cosas que destaco de Delphi Tools es el generador de código QR así como los editores de imágenes. No sé si tenga más o la misma cantidad de características como IT Tools, Omni Tools o Dev Toys pero aquí la gracia no es compararlos sino disfrutarlos 😆
在 Delphi Tools 中，我特别推崇它的二维码生成器以及图像编辑器。我不知道它是否比 IT Tools、Omni Tools 或 Dev Toys 拥有更多或相同数量的功能，但这里的乐趣不在于比较它们，而在于享受它们带来的便利 😆
