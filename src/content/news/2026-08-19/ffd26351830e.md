# Learning Discrete Riemannian Metrics for Physical Fields with Cochain-Frame Equivariance
# 学习用于物理场的具有上链框架等变性的离散黎曼度量

**Abstract:** Physical fields on meshes require a separation between topology and geometry: conservation laws are topological and should be exact, while geometry, material response, and anisotropic coupling must be learned from data. 

**摘要：** 网格上的物理场需要将拓扑与几何分离开来：守恒定律是拓扑性的，应当是精确的；而几何、材料响应和各向异性耦合则必须从数据中学习。

Existing neural surrogates often mix these roles inside unconstrained message passing. We introduce Riemannian Hodge Message Passing (RHMP), which turns this separation into an architectural principle. 

现有的神经代理模型通常在无约束的消息传递中混淆了这些角色。我们引入了黎曼霍奇消息传递（Riemannian Hodge Message Passing, RHMP），将这种分离转化为一种架构原则。

RHMP fixes the cellular coboundaries ($d_k$) determined by oriented incidence and learns symmetric positive-definite cochain metrics ($H_k$) for geometry-dependent propagation. 

RHMP 固定了由定向关联决定的胞腔上边界算子（$d_k$），并学习用于几何相关传播的对称正定上链度量（$H_k$）。

Treating $H_k$ as the learned metric motivates cochain-frame equivariance: physical propagation should be invariant to orthogonal changes of the hidden cochain feature basis. 

将 $H_k$ 视为学习到的度量，从而引出了上链框架等变性（cochain-frame equivariance）：物理传播应当对隐藏上链特征基的正交变换保持不变。

RHMP implements this principle with metric-weighted Hodge blocks ($d_k^\top H_{k+1}d_k$), yielding exact cochain-complex identities ($d_{k+1}d_k=0$), nonnegative Hodge energies, positive-semidefinite operators, and exact Abelian curvature invariance. 

RHMP 通过度量加权的霍奇块（$d_k^\top H_{k+1}d_k$）实现了这一原则，从而产生精确的上链复形恒等式（$d_{k+1}d_k=0$）、非负霍奇能量、半正定算子以及精确的阿贝尔曲率不变性。

Across seven physical benchmarks spanning fluids, electromagnetism, gauge fields, and variable-mesh CFD, RHMP achieves the best overall performance, with the largest gains when topology, learned geometry, and field structure interact.

在涵盖流体、电磁学、规范场和变网格计算流体动力学（CFD）的七个物理基准测试中，RHMP 均取得了最佳的整体性能，特别是在拓扑、学习到的几何结构和场结构相互作用时，性能提升最为显著。
