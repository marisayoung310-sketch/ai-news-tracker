# How to Orchestrate a Fleet of OpenClaw Bots
# 如何编排 OpenClaw 机器人集群

**Agentic AI: How to Orchestrate a Fleet of OpenClaw Bots**
**智能体 AI：如何编排 OpenClaw 机器人集群**

In this article I’ll discuss how to effectively use OpenClone to automate tasks. Millions of people are running Claude Code every day to get tasks done, mostly related to programming. Claude Code is great when you need to perform specific tasks. For example, if you’re assigned a specific task to do or if you’re working on a project.
在本文中，我将探讨如何有效利用 OpenClone 来实现任务自动化。每天有数百万人运行 Claude Code 来完成任务，其中大部分与编程相关。当你需要执行特定任务时，Claude Code 非常出色。例如，当你被分配了具体任务或正在进行某个项目时。

However, Claude Code and other similar coding agents don’t work as well in proactive work. So basically, when you need to do something unprompted. This is where OpenClaw comes in very clutch. OpenClaw agents are essentially coding agents that run 24/7. You can have them run in an application such as Slack or Telegram, and in essence, they work very similarly to a traditional coding agent.
然而，Claude Code 和其他类似的编程智能体在主动性工作方面表现并不理想。也就是说，当你需要处理一些非提示性的任务时，OpenClaw 就显得至关重要了。OpenClaw 智能体本质上是 24/7 全天候运行的编程智能体。你可以让它们在 Slack 或 Telegram 等应用程序中运行，从本质上讲，它们的工作方式与传统的编程智能体非常相似。

The main difference is that you access them via apps such as Slack, and they have some infrastructure around them, such as setting up cron jobs and so on. In this article, I’ll discuss how you can set up a fleet of OpenClaw agents and have them effectively perform a lot of work for you proactively. This can help you a lot not only in coding tasks but also in any other task that you have to run within a business, for example, customer success management, finance management, sales, and so on.
主要的区别在于，你是通过 Slack 等应用访问它们，并且它们周围具备一些基础设施，例如设置定时任务（cron jobs）等。在本文中，我将讨论如何设置一个 OpenClaw 智能体集群，并让它们主动为你高效地完成大量工作。这不仅在编程任务中对你有很大帮助，在企业内部需要运行的任何其他任务中也能提供支持，例如客户成功管理、财务管理、销售等。

**Knowledge base**
**知识库**

Having a knowledge base is one important topic that I think you should think about when setting up OpenClaw agents. I have two kinds of knowledge bases. One is the shared knowledge base that everyone in the company has access to, and that the coding agents consistently update whenever they have new knowledge added, new documents added, and so on.
拥有知识库是我认为你在设置 OpenClaw 智能体时应该考虑的一个重要课题。我有两种知识库。一种是公司内每个人都可以访问的共享知识库，每当有新知识、新文档等添加时，编程智能体会持续更新它。

I think this is super valuable, both to have all knowledge gathered in one location so that anyone, whether it’s a human or an agent, can find it on demand. It’s also worth knowing that when you set up this knowledge base, you should have a markdown file at the root that indexes all the content in the knowledge base, the structure of it, where to find certain information, and so on.
我认为这非常有价值，既能将所有知识汇集在一个地方，以便任何人（无论是人类还是智能体）都能按需查找。同样值得注意的是，在设置此知识库时，你应该在根目录下放置一个 Markdown 文件，用于索引知识库中的所有内容、结构以及查找特定信息的位置等。

The second type of knowledge base that you should have is a bot personal knowledge base, which is basically knowledge the bot builds up over time. This is a knowledge base you can update with a daily cron job where the agent learns from its interactions that day. If you have this setup, you’ll notice that the agents will improve over time and get better and better, which is super helpful for you when you want an effective fleet of OpenClaw agents. You should make sure to set this up for all of your agents so that all of them improve over time.
你应该拥有的第二种知识库是机器人个人知识库，这基本上是机器人随着时间推移而积累的知识。这是一个你可以通过每日定时任务更新的知识库，智能体从中学习当天的交互内容。如果你进行了此设置，你会发现智能体会随着时间的推移不断进步，变得越来越好，这对于你想要一个高效的 OpenClaw 智能体集群非常有帮助。你应该确保为所有的智能体都进行此设置，以便它们都能随着时间的推移不断改进。
