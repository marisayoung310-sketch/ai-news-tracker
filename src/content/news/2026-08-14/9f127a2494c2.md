# DeepSeek Harness 开发者预览版发布

**DeepSeek Harness developer preview**
DeepSeek Harness 现已面向全球智能体（Agent）框架开发者推出开发者预览版，并已开源源代码。

**Everything is a plugin**
每一项功能都是一个插件，可以进行替换或重组：包括模型、工具、技能、会话、沙箱、存储、循环、调度以及用户界面（UI）。

**Agent = Model + Harness**
模型是智能体的灵魂，而 Harness（框架）则让智能体能够理解其环境、使用工具，并在现实世界中持续运行。

**Cordis kernel**
Cordis 内核负责管理插件的挂载、卸载及依赖关系。智能体的各项能力均由插件实现。

**Capabilities as plugins**
插件提供了智能体的所有能力，包括模型、工具、技能、会话、沙箱、存储、循环、调度和 UI。Cordis 的服务与事件机制让这些插件能够协同工作。

**Compose with configuration**
开发者无需修改 DeepSeek Harness 的源代码，仅通过配置即可选择、替换或扩展任何功能。

**Everything is a plugin**
DeepSeek Harness 构建于 Cordis 插件系统之上。插件提供了智能体的所有能力，包括模型、工具、技能、会话、沙箱、存储、循环、调度和 UI。Cordis 的服务与事件机制让这些插件能够协同工作。开发者无需修改 DeepSeek Harness 的源代码，仅通过配置即可选择、替换或扩展任何功能。

**Every run is traceable**
模型所见的一切都会被记录在只读的会话日志中：包括系统提示词、推理过程、工具调用及其结果、子智能体调度以及每一次上下文注入。在“轨迹视图”（Trajectory view）中，你可以按来源检查这些记录。恢复、分支、搜索和重放操作均基于同一事件流进行。

**Multiple runtime modes**
*   **标准模式（Standard mode）**：包含全套工具集。
*   **代码模式（Code mode）**：使用模型生成的代码来编排多轮工具调用。
*   **极简模式（Minimal mode）**：仅保留 Shell 工具和文件编辑器，用于在极简环境中对模型进行基准测试。
*   **创建者模式（Creator mode）**：允许你检查当前运行时、在内存中测试 Cordis 插件，并将它们组合成新的模式。

**Standard mode**
功能完备的编程智能体，具备文件编辑、Shell、文件与网页搜索、技能、规划、目标设定、子智能体及工作流功能。

**Code mode**
具备标准模式的所有能力，且工具通过 Code Mode SDK 暴露，使模型能够在一个 TypeScript 程序中组合多步操作。

**Minimal mode**
仅包含两个工具的编程智能体，配备持久化 Bash 和 `str_replace_editor`。

**Creator mode**
专为创建自定义智能体预设而设计，具备标准模式的所有能力，并增加了运行时检查、插件实验和预设编写指南。

**Customize your DeepSeek Harness**
开始使用：立即尝试或从源码安装。

**Quick start**
安装 Node.js，然后通过 `npx` 启动 Web UI：
`$ npx @deepseek-ai/dsh web`

**Install from source**
克隆完整源码并按照仓库中的设置说明进行操作：
`$ git clone https://github.com/deepseek-ai/deepseek-harness`
