# MetaRoute-Bench: Evaluating Meta-Decision Policies for Agentic Workflow Routing
# MetaRoute-Bench：评估智能体工作流路由的元决策策略

**Abstract:** Agentic systems must repeatedly decide whether to answer directly, decompose a task, invoke a tool, execute code, delegate to a specialist, verify an intermediate result, or recover from failure. These meta-decisions affect not only task success but also operating cost and latency, yet they are often embedded inside an orchestration framework and evaluated only through aggregate task accuracy.

**摘要：** 智能体系统必须反复做出决策：是直接回答、分解任务、调用工具、执行代码、委派给专家、验证中间结果，还是从故障中恢复。这些元决策不仅影响任务的成功率，还影响运营成本和延迟，但它们通常被嵌入在编排框架内部，且仅通过任务的总体准确率进行评估。

We present MetaRoute-Bench, an open, inspectable framework for comparing meta-decision policies under a shared execution model. The initial benchmark contains 180 synthetic task profiles spanning data analysis, research, and document processing, eight routing policies, and 30 paired random seeds.

我们提出了 MetaRoute-Bench，这是一个开放且可审查的框架，用于在共享执行模型下比较元决策策略。该基准测试的初始版本包含 180 个合成任务配置文件，涵盖数据分析、研究和文档处理，以及八种路由策略和 30 组配对随机种子。

Across 43,200 traces, a task-aware compositional policy achieves 79.4% success compared with 76.7% for a strong workload-specific static policy, 67.4% for one-shot task routing, and 52.9% for direct answering. Relative to the static policy, this is a 2.7 percentage-point improvement with paired 95% CI of plus or minus 2.0 points, at 4.7% higher mean cost and 6.4% higher latency.

在 43,200 条追踪记录中，任务感知组合策略实现了 79.4% 的成功率，相比之下，强大的工作负载特定静态策略为 76.7%，单次任务路由为 67.4%，直接回答为 52.9%。相对于静态策略，这提升了 2.7 个百分点（配对 95% 置信区间为 ±2.0 个百分点），但平均成本增加了 4.7%，延迟增加了 6.4%。

Ablations show the largest losses when route composition is restricted to one operation and when verification is removed. These results are generated by a seeded offline execution model rather than a live deployment; accordingly, the primary contribution is a reproducible evaluation method and an analysis of routing-policy tradeoffs, not evidence of production effectiveness. We release task generation, policies, traces, tests, and analysis artifacts to support live-system validation.

消融实验表明，当路由组合被限制为单一操作以及移除验证步骤时，性能损失最为严重。这些结果是由种子离线执行模型生成的，而非实时部署环境；因此，本研究的主要贡献在于提供了一种可复现的评估方法和对路由策略权衡的分析，而非生产环境有效性的证据。我们发布了任务生成器、策略、追踪记录、测试用例和分析工件，以支持实时系统的验证。
