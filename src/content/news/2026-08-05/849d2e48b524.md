# Lenovo’s Legion Go S with SteamOS is down to its lowest price ever
# 联想 Legion Go S (SteamOS版) 迎来史低价

The Steam Deck OLED recently got a price bump, but the next best SteamOS handheld just got cheaper.
Steam Deck OLED 近期价格有所上涨，但另一款优秀的 SteamOS 掌机却变得更便宜了。

Memory and storage prices will be inflated for the foreseeable future, so we’re always happy to find a good deal on capable gaming hardware, like this discount on the Lenovo Legion Go S with a Z2 Go processor and SteamOS. Normally $1,137.41 (and selling for close to $1,000 at Best Buy), Lenovo has the handheld console on sale for just $635.54 when you use code EXTRASAVEAFF at checkout, the lowest price we’ve seen yet for this model.
由于内存和存储价格在可预见的未来仍将居高不下，我们总是乐于见到高性能游戏硬件的折扣，比如这次搭载 Z2 Go 处理器和 SteamOS 的联想 Legion Go S。该机型原价为 1,137.41 美元（在百思买售价接近 1,000 美元），现在在联想官网结账时使用优惠码 EXTRASAVEAFF，仅需 635.54 美元即可入手，这是该型号目前为止我们见过的最低价格。

We reviewed both the Windows and SteamOS versions of this gaming handheld when it released in 2024, and found the latter to be a much more appealing option, largely thanks to the improved user experience that Windows has shown signs that it’s slowly catching up to. The Z2 Go chip isn’t all that impressive, with similar performance to the more expensive OLED Steam Deck, but it’s still a solid choice for indie games and more spec-intensive titles if you turn the settings down. The 8-inch IPS panel goes up to 120Hz, and has variable refresh rate, which helps the Legion Go S stand out among other options at the same price.
我们在 2024 年该掌机发布时评测了 Windows 和 SteamOS 两个版本，发现后者更具吸引力，这主要归功于其更出色的用户体验——尽管 Windows 版本目前也显示出正在缓慢追赶的迹象。Z2 Go 芯片的表现并不算惊艳，性能与价格更高的 OLED 版 Steam Deck 相当，但对于独立游戏以及调低画质后的高负载游戏来说，它依然是一个稳妥的选择。其 8 英寸 IPS 面板支持高达 120Hz 的刷新率，并具备可变刷新率（VRR）功能，这使得 Legion Go S 在同价位产品中脱颖而出。
