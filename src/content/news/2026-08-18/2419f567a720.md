# The Query Knows What to Forget: A Second Erase Direction for Linear Attention
# 查询知道该遗忘什么：线性注意力机制的第二个擦除方向

**Abstract:** Linear attention keeps a state of fixed size. At long context, many stored items share this state, and interference between them degrades retrieval. Gated DeltaNet-2 (GDN-2), like every delta-rule model before it, derives its erase vector from the key of the current token. However, the interference in its reads is measured through the query, and the erase step cannot reach it.

**摘要：** 线性注意力机制保持着固定大小的状态。在长上下文场景中，许多存储项共享这一状态，它们之间的干扰会降低检索性能。Gated DeltaNet-2 (GDN-2) 与之前所有的 Delta 规则模型一样，其擦除向量源自当前 Token 的 Key（键）。然而，读取过程中的干扰是通过 Query（查询）来衡量的，而擦除步骤却无法触及这一部分。

We introduce the Query-derived Erase Direction (QED). QED adds a second erase direction derived from the query and orthogonal to the key. In the fast-weight view, a key-directed delta edit cannot change the key-orthogonal part of a read. It uses the editable part to cancel old-state content measured along the query. It also improves retrieval at every length past the training window, and it about doubles the usable context length on S-NIAH-1.

我们引入了“查询派生擦除方向”（Query-derived Erase Direction, QED）。QED 增加了一个源自 Query 且与 Key 正交的第二个擦除方向。在快速权重（fast-weight）视角下，基于 Key 的 Delta 编辑无法改变读取中与 Key 正交的部分。它利用可编辑部分来抵消沿 Query 衡量的旧状态内容。该方法还提升了超出训练窗口长度后的检索性能，并在 S-NIAH-1 测试集上将可用上下文长度提高了一倍左右。
