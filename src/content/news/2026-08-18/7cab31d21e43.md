# Kolmogorov-Arnold Networks for Spatially Independent Multispectral Land Classification
# 用于空间独立多光谱土地分类的 Kolmogorov-Arnold 网络

**Abstract:** Land classification from satellite imagery is important for land management, environmental monitoring, and urban planning. Machine learning methods such as random forests and multilayer perceptrons have shown strong performance on multispectral data, while the Kolmogorov-Arnold network has emerged as an alternative architecture with compact model structures.

**摘要：** 基于卫星影像的土地分类对于土地管理、环境监测和城市规划至关重要。随机森林和多层感知机等机器学习方法在多光谱数据上表现出了强大的性能，而 Kolmogorov-Arnold 网络作为一种具有紧凑模型结构的新兴替代架构也随之出现。

This study evaluates the Kolmogorov-Arnold network for land classification using Landsat 8 imagery and compares it with random forest and multilayer perceptron models. The models were trained and tested on data from Edmonton, Alberta and evaluated on an independent dataset from Calgary, Alberta across five land classes: agriculture, urban, water, forest, and bare ground.

本研究评估了 Kolmogorov-Arnold 网络在利用 Landsat 8 影像进行土地分类方面的表现，并将其与随机森林和多层感知机模型进行了比较。这些模型在艾伯塔省埃德蒙顿的数据上进行了训练和测试，并在艾伯塔省卡尔加里的独立数据集上进行了评估，涵盖了农业用地、城市用地、水域、森林和裸地五种土地类型。

For the Calgary dataset, the Kolmogorov-Arnold network matched the accuracy of the random forest and outperformed the multilayer perceptron, while requiring substantially fewer trainable parameters and providing greater interpretability.

在卡尔加里数据集上，Kolmogorov-Arnold 网络的准确率与随机森林相当，且优于多层感知机，同时其所需的可训练参数显著减少，并提供了更好的可解释性。
