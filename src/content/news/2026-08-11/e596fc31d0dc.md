# paperclipai / paperclip

Paperclip is the app people use to manage AI agents for work. Open-source orchestration for teams of AI agents. If OpenClaw is an employee, Paperclip is the company.
Paperclip 是人们用于管理工作 AI 代理的应用程序。它是 AI 代理团队的开源编排工具。如果说 OpenClaw 是员工，那么 Paperclip 就是公司。

Paperclip is a Node.js server and React UI that orchestrates a team of AI agents to run a business. Bring your own agents, assign goals, and track work and costs from one dashboard. It looks like a task manager. Under the hood: org charts, budgets, governance, goal alignment, and agent coordination. Manage business goals, not pull requests.
Paperclip 是一个 Node.js 服务器和 React UI，用于编排 AI 代理团队以运营业务。你可以引入自己的代理，分配目标，并从一个仪表板跟踪工作和成本。它看起来像一个任务管理器。其底层逻辑包括：组织架构图、预算、治理、目标对齐和代理协调。管理业务目标，而不是 Pull Request。

要让 AI 代理组织真正产出成果，必须做好四件事：任务、组织、培训和基础设施。Paperclip 正是围绕这四个支柱构建的。

### Features
### 功能特性

* 🔌 **Bring Your Own Agent**: Any agent, any runtime, one org chart. If it can receive a heartbeat, it's hired.
* 🔌 **自带代理 (BYOA)**：任何代理、任何运行时，统一组织架构图。只要能接收心跳信号，就能被录用。
* 🎯 **Goal Alignment**: Every task traces back to the company mission. Agents know what to do and why.
* 🎯 **目标对齐**：每项任务都可追溯至公司使命。代理清楚要做什么以及为什么做。
* 💓 **Heartbeats**: Agents wake on a schedule, check work, and act. Delegation flows up and down the org chart.
* 💓 **心跳机制**：代理按计划唤醒、检查工作并采取行动。授权在组织架构图中上下流动。
* 💰 **Cost Control**: Monthly budgets per agent. When they hit the limit, they stop. No runaway costs.
* 💰 **成本控制**：每个代理的月度预算。达到限额即停止，杜绝失控成本。
* 🏢 **Multi-Company**: One deployment, many companies. Complete data isolation. One control plane for your portfolio.
* 🏢 **多公司支持**：一次部署，管理多家公司。数据完全隔离。为你的投资组合提供统一控制平面。
* 🎫 **Ticket System**: Every conversation traced. Every decision explained. Full tool-call tracing and immutable audit log.
* 🎫 **工单系统**：追踪每一次对话。解释每一个决策。完整的工具调用追踪和不可篡改的审计日志。
* 🛡️ **Governance**: Approve hires, override strategy, pause or terminate any agent — at any time.
* 🛡️ **治理**：随时批准录用、覆盖策略、暂停或终止任何代理。
* 📊 **Org Chart**: Hierarchies, roles, reporting lines. Your agents have a boss, a title, and a job description.
* 📊 **组织架构图**：层级、角色、汇报线。你的代理拥有上司、头衔和职位描述。
* 📱 **Mobile Ready**: Monitor and manage your autonomous businesses from anywhere.
* 📱 **移动端就绪**：随时随地监控和管理你的自主业务。

### Why Paperclip is special
### 为什么 Paperclip 与众不同

* **Atomic execution**: Task checkout and budget enforcement are atomic, so no double-work and no runaway spend.
* **原子化执行**：任务签出和预算执行是原子化的，因此不会出现重复工作或失控支出。
* **Persistent agent state**: Agents resume the same task context across heartbeats instead of restarting from scratch.
* **持久化代理状态**：代理在心跳间隔之间恢复相同的任务上下文，而不是从头开始。
* **Runtime skill injection**: Agents can learn Paperclip workflows and project context at runtime, without retraining.
* **运行时技能注入**：代理可以在运行时学习 Paperclip 工作流和项目上下文，无需重新训练。
* **Governance with rollback**: Approval gates are enforced, config changes are revisioned, and bad changes can be rolled back safely.
* **带回滚的治理**：强制执行审批门控，配置变更具有版本控制，错误的变更可以安全回滚。
* **Goal-aware execution**: Tasks carry full goal ancestry so agents consistently see the "why," not just a title.
* **目标感知执行**：任务携带完整的目标溯源，因此代理始终能看到“为什么”，而不仅仅是一个标题。
* **Portable company templates**: Export/import orgs, agents, and skills with secret scrubbing and collision handling.
* **可移植的公司模板**：导出/导入组织、代理和技能，并具备密钥清理和冲突处理功能。
* **True multi-company isolation**: Every entity is company-scoped, so one deployment can run many companies with separate data and audit trails.
* **真正的多公司隔离**：每个实体都限定在公司范围内，因此一次部署可以运行多家公司，并拥有独立的数据和审计追踪。
