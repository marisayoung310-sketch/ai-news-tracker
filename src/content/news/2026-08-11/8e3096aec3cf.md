### Introduction / 引言

Autoencoders have been an incredible innovation. Their ability to compress data within the bottleneck allows them to solve downstream tasks more efficiently than would otherwise be possible, avoiding the excessive computation required to process high-dimensional input data. In addition, we saw in the article about autoencoders that they can be used to solve other computer vision tasks, such as image denoising, object removal, or image inpainting.
自编码器是一项了不起的创新。它们在瓶颈层压缩数据的能力，使其能够比直接处理高维输入数据更高效地解决下游任务，从而避免了过度的计算开销。此外，正如我们在关于自编码器的文章中所看到的，它们还可以用于解决其他计算机视觉任务，例如图像去噪、物体移除或图像修复。

While vanilla autoencoders might seem powerful, they still have several limitations that can be improved. Given that, the researchers developed a more advanced version called variational autoencoders. We are going to study them in this article.
虽然普通自编码器看起来很强大，但它们仍存在一些可以改进的局限性。鉴于此，研究人员开发了一种更高级的版本，即变分自编码器 (VAE)。我们将在本文中深入研究它们。

### Motivation / 动机

In the previous article, we mostly discussed data compression as the main application of autoencoders. In reality, there are other interesting aspects we can look at.
在上一篇文章中，我们主要讨论了数据压缩作为自编码器的主要应用。实际上，还有其他值得关注的有趣方面。

#### Similarity / 相似性

If you conduct experiments and try to calculate the distance between objects in latent space, you will find that, in many cases, the similarity properties between objects are not preserved to the same extent as in other common embedding algorithms. This happens because, during training, the model focuses primarily on reconstructing the original images rather than on the internal representations within latent space.
如果你进行实验并尝试计算潜在空间中物体之间的距离，你会发现，在许多情况下，物体之间的相似性属性并没有像其他常见的嵌入算法那样得到很好的保留。这是因为在训练过程中，模型主要关注的是重建原始图像，而不是潜在空间内部的表示。

For example, if you take two similar images and pass them into a learned autoencoder, they are likely to be less close to each other in the latent space than with other algorithms. The same would go for dissimilar objects, which can be close to each other. As a result, similarity preservation is a weakness of vanilla autoencoders.
例如，如果你取两张相似的图像并将其输入到一个已训练好的自编码器中，它们在潜在空间中的距离可能比使用其他算法时更远。同样，不相似的物体也可能在潜在空间中靠得很近。因此，相似性保持是普通自编码器的一个弱点。

#### Image generation / 图像生成

Decoders are very good at reconstructing original images. As a result, a question that has attracted the attention of many researchers is whether, with the autoencoder architecture, it would be possible to generate high-quality new images. Given that the decoder generates images from latent space, a natural way to generate new images is to sample new points from latent space and pass them as input to the decoder.
解码器在重建原始图像方面表现非常出色。因此，一个吸引了许多研究人员关注的问题是：利用自编码器架构，是否有可能生成高质量的新图像？鉴于解码器是从潜在空间生成图像的，生成新图像的一种自然方法是从潜在空间采样新点，并将它们作为输入传递给解码器。

Unfortunately, the quality of the generated images is usually poor. Even if there is an encoded object in the latent space and a new point is sampled in its neighborhood, it seems logical that a generated image from that point would look very similar to the original. But again, this is not always true.
遗憾的是，生成图像的质量通常很差。即使潜在空间中存在一个已编码的物体，并在其邻域内采样了一个新点，从逻辑上讲，该点生成的图像应该看起来与原始图像非常相似。但事实并非总是如此。

An analogous scenario would occur if you took a point midway between two embedded objects in the latent space. For instance, let’s imagine that object A is an image of a smiling person, while object B is an image of a person with a disappointed expression. If we sample a new point C midway between the two, in the ideal case, we would expect the decoder to generate an image of someone with a neutral facial expression. An autoencoder will likely fail to do this.
如果你在潜在空间中取两个嵌入物体之间的中点，也会出现类似的情况。例如，假设物体 A 是一个微笑的人的图像，而物体 B 是一个表情失望的人的图像。如果我们采样一个位于两者之间的中点 C，在理想情况下，我们期望解码器生成一个表情中性的人的图像。而普通自编码器很可能无法做到这一点。

Given all of that, the main motivations for a new autoencoder version are related to how the latent space is constructed. We want the latent space to preserve similarity properties among embedded objects. This will allow us to perform geometric tricks with object distances and to sample new points in the space to generate new images.
综上所述，开发新版自编码器的主要动机与潜在空间的构建方式有关。我们希望潜在空间能够保留嵌入物体之间的相似性属性。这将使我们能够对物体距离进行几何运算，并从空间中采样新点以生成新图像。

### Methodology / 方法论

Let’s introduce formal notation to help us derive mathematical results. We already have two distinct spaces:
让我们引入正式的符号来帮助推导数学结果。我们已经有了两个不同的空间：

*   The real space where the data distribution $p(x)$ contains real images.
    真实空间，其中数据分布 $p(x)$ 包含真实图像。
*   The latent space that contains all possible latent vectors.
    潜在空间，包含所有可能的潜在向量。

Those two spaces are separate, and we would need functions to connect images from both spaces. To that end, we are going to introduce two distributions:
这两个空间是分离的，我们需要函数来连接这两个空间中的图像。为此，我们将引入两个分布：

*   Posterior distribution $p(z | x)$ returns the probability that a latent vector $z$ was generated from image $x$.
    后验分布 $p(z | x)$，返回潜在向量 $z$ 由图像 $x$ 生成的概率。
*   Likelihood distribution $p(x | z)$ that, given a vector $z$, reconstructs an image $x$ from it.
    似然分布 $p(x | z)$，给定向量 $z$，从中重建图像 $x$。

The overall idea is simple: if we can sample vectors $z$ from the posterior distribution $p(z | x)$, we could use them to reconstruct and generate realistic images from the original distribution using the decoder (or the likelihood distribution) $p(x | z)$. The problem is that we do not know the form of the posterior distribution $p(z | x)$. In other words, it is intractable, so we cannot compute or sample from it directly.
总体思路很简单：如果我们能从后验分布 $p(z | x)$ 中采样向量 $z$，我们就可以利用解码器（或似然分布）$p(x | z)$ 使用它们来重建和生成来自原始分布的真实图像。问题在于我们不知道后验分布 $p(z | x)$ 的形式。换句话说，它是不可计算的，因此我们无法直接计算或从中采样。

---

### Approximation idea / 近似思路

To solve the problem above, VAE assumes that the latent distribution is normal, $N(0, 1)$. This allows estimation of $p(x | z)$. In addition, VAE proposes to approximate the posterior distribution $p(z | x)$ with a normal distribution $q(z | x) = N(\mu, \sigma)$ with learned parameters $\mu$ and $\sigma$, using an encoder. To train the whole model, we would need to define a loss function. For that, we are going to use ELBO estimation.
为了解决上述问题，VAE 假设潜在分布是正态分布 $N(0, 1)$。这使得估计 $p(x | z)$ 成为可能。此外，VAE 提出使用编码器，通过一个带有可学习参数 $\mu$ 和 $\sigma$ 的正态分布 $q(z | x) = N(\mu, \sigma)$ 来近似后验分布 $p(z | x)$。为了训练整个模型，我们需要定义一个损失函数。为此，我们将使用 ELBO 估计。

---

### Training objective / 训练目标

First, we set the objective to maximize the log-likelihood of $p(x)$. Why? Let’s suppose that $x_i$ is a random image from the training dataset. Then we are trying to maximize the following expression: $\log p(x_1) + \log p(x_2) + \dots + \log p(x_n)$.
首先，我们将目标设定为最大化 $p(x)$ 的对数似然。为什么？假设 $x_i$ 是训练数据集中的一张随机图像。那么我们试图最大化以下表达式：$\log p(x_1) + \log p(x_2) + \dots + \log p(x_n)$。

If a model learns to assign high probabilities to $x_i$, indicating that they are realistic images, then it automatically learns how the real data look. It is the most logical training objective we can use. As a consequence, maximizing log-likelihood will make unrealistic images outside the training dataset have lower probabilities. Given that, our goal is now to derive the loss function. To do so, we will use the ELBO.
如果模型学会为 $x_i$ 分配高概率，表明它们是真实的图像，那么它就自动学会了真实数据的样子。这是我们能使用的最合乎逻辑的训练目标。因此，最大化对数似然将使训练数据集之外的不真实图像具有较低的概率。鉴于此，我们的目标现在是推导损失函数。为此，我们将使用 ELBO。

---

### ELBO / ELBO

ELBO stands for Evidence Lower Bound. It is a very useful lower bound on the log-likelihood.
ELBO 代表证据下界 (Evidence Lower Bound)。它是对数似然的一个非常有用的下界。
