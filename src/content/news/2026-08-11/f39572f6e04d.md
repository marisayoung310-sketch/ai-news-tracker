# SPP-Net Paper Walkthrough: Breaking the Fixed-Size Constraint
# SPP-Net 论文详解：打破固定尺寸限制

Deep Learning SPP-Net Paper Walkthrough: Breaking the Fixed-Size Constraint. Learn how Spatial Pyramid Pooling enables CNNs to handle any image size, with a from-scratch PyTorch implementation.
深度学习 SPP-Net 论文详解：打破固定尺寸限制。了解空间金字塔池化（Spatial Pyramid Pooling）如何使 CNN 处理任意图像尺寸，并附带从零开始的 PyTorch 实现。

In the past, a CNN model needed to have a fixed input dimension. This was actually a problem because objects in our surroundings have varying dimensions. With humans and cars, for example, we cannot use the exact same bounding box to approximate them since humans tend to have a vertical shape while it is more appropriate to approximate a car with a horizontal bounding box.
在过去，CNN 模型需要固定的输入维度。这实际上是一个问题，因为我们周围的物体具有不同的尺寸。例如，对于人和汽车，我们不能使用完全相同的边界框来近似它们，因为人往往呈垂直形状，而用水平边界框来近似汽车则更为合适。

The easiest way to address this issue is by using either cropping or warping, and by doing so we can set an image to have a specific size. However, if the image is cropped, the cropped area might cut off part of the object, while if we warp the image, we will have the object distorted. These transformations clearly cause the visual appearance of the objects to change weirdly, thus it might potentially reduce model accuracy if we were to use them to train a classification model. Take a look at Figure 1 below to better understand what I mean.
解决这个问题最简单的方法是使用裁剪或变形，通过这种方式，我们可以将图像设置为特定尺寸。然而，如果图像被裁剪，裁剪区域可能会切掉物体的一部分；而如果对图像进行变形，物体就会失真。这些变换显然会导致物体的视觉外观发生奇怪的变化，因此如果我们使用它们来训练分类模型，可能会降低模型精度。请看下图 1，以更好地理解我的意思。

Figure 1. Examples of how cropping (left) and warping (right) respectively truncate and distort image content [1].
图 1. 裁剪（左）和变形（右）分别截断和扭曲图像内容的示例 [1]。

In this article we are going to talk about SPP-Net, a CNN-based model that can accept images of varying sizes so that we can completely avoid using cropping or warping mechanism. Not only that, here I will also try to implement it from scratch with PyTorch so that you can get a better understanding about the detailed architecture.
在本文中，我们将讨论 SPP-Net，这是一种基于 CNN 的模型，可以接受不同尺寸的图像，从而完全避免使用裁剪或变形机制。不仅如此，我还将尝试用 PyTorch 从零开始实现它，以便您能更好地理解其详细架构。

### A Brief History of SPP-Net
### SPP-Net 简史

SPP-Net was introduced in a paper titled “Spatial Pyramid Pooling in Deep Convolutional Networks for Visual Recognition” written by He et al. back in June 2014 [1]. It is important to note that SPP itself already existed long before this paper. So, what this paper essentially proposed was SPP-Net, which is the very first model to integrate the idea of SPP on a CNN.
SPP-Net 是由何恺明等人于 2014 年 6 月发表的论文《深度卷积网络中的空间金字塔池化用于视觉识别》（Spatial Pyramid Pooling in Deep Convolutional Networks for Visual Recognition）中提出的 [1]。需要注意的是，SPP 本身在这篇论文发表之前就已经存在很久了。因此，这篇论文本质上提出的是 SPP-Net，它是第一个将 SPP 思想集成到 CNN 中的模型。

### CNN vs SPP-Net
### CNN 与 SPP-Net

Figure 2. The flow of the conventional CNN architecture (top) vs the flow of a CNN with SPP layer (bottom) [1].
图 2. 传统 CNN 架构的流程（上）与带有 SPP 层的 CNN 流程（下）对比 [1]。

The upper flowchart in Figure 2 displays the workflow of the conventional CNN model. This process requires us to perform cropping or warping to make the images in the dataset have uniform size before passing them through the model. Meanwhile, the lower flowchart in the figure shows the flow when we use SPP layer in the CNN. Here you can see that we don’t need the cropping or warping step since we already have the SPP layer placed between the convolution layers and the fully-connected layers within the network.
图 2 中的上方流程图展示了传统 CNN 模型的工作流程。该过程要求我们在将图像输入模型之前，必须进行裁剪或变形，以使数据集中的图像具有统一的尺寸。与此同时，图中的下方流程图展示了在 CNN 中使用 SPP 层时的流程。在这里你可以看到，我们不再需要裁剪或变形步骤，因为我们已经在网络中的卷积层和全连接层之间放置了 SPP 层。

If we take a closer look at the CNN architecture, what basically makes the conventional CNN able to only accept a fixed-size tensor is its fully-connected layer. The convolution layers themselves can naturally accept input of varying sizes due to the shared weights across the spatial dimension of the image. For instance, if we have a conv layer with a 3×3 kernel, then we will have 9 trainable weights (or 10 if we include the bias term) regardless of the size of the image passed through the network.
如果我们仔细观察 CNN 架构，传统 CNN 只能接受固定尺寸张量的根本原因在于其全连接层。由于卷积层在图像的空间维度上共享权重，它们本身可以自然地接受不同尺寸的输入。例如，如果我们有一个带有 3×3 核的卷积层，那么无论通过网络的图像尺寸如何，我们都将拥有 9 个可训练权重（如果包含偏置项则为 10 个）。

This property is different from a fully-connected layer, where every single element in the tensor needs to have its corresponding weight. For example, if we have an image of size 10×10, we need to flatten it into a single-dimensional tensor of length 100, and thus we will also need that same number of weights (or 101 with the bias term). This essentially means that if the shape of the input tensor changes, then we will require a different number of weights as well. This behavior makes an FC layer unsuitable for processing images of varying resolutions.
这种特性与全连接层不同，在全连接层中，张量中的每一个元素都需要有对应的权重。例如，如果我们有一张 10×10 的图像，我们需要将其展平为长度为 100 的一维张量，因此我们也需要相同数量的权重（如果包含偏置项则为 101 个）。这本质上意味着，如果输入张量的形状发生变化，那么我们也需要不同数量的权重。这种行为使得全连接层不适合处理不同分辨率的图像。

With this problem in mind, the authors of SPP-Net proposed a mechanism where we can still utilize the property of CNN in handling varying input sizes while adapting the extracted feature map to a fixed-size vector required by the fully-connected layer. This is essentially the reason why in Figure 2 they placed the SPP layer between the stack of convolutions and the FC layers.
考虑到这个问题，SPP-Net 的作者提出了一种机制，使我们既能利用 CNN 处理不同输入尺寸的特性，又能将提取的特征图适配为全连接层所需的固定尺寸向量。这本质上就是为什么在图 2 中，他们将 SPP 层放置在卷积堆栈和全连接层之间的原因。

### How SPP Layer Works
### SPP 层的工作原理

Figure 3 below displays the detailed steps of how SPP-Net processes an image. In accordance with the lower flowchart in Figure 2, we initially pass the raw image through a stack of convolution layers. In one of their experiments, they used a network of 5 convolutions which they refer to as conv₁, conv₂, conv₃, conv₄ and conv₅. For the sake of simplicity, the figure below only displays the tensor produced by the last convolution, which is the one to be forwarded to the SPP layer.
下图 3 展示了 SPP-Net 处理图像的详细步骤。根据图 2 中的下方流程图，我们首先将原始图像通过一系列卷积层。在他们的一个实验中，他们使用了一个包含 5 个卷积层的网络，分别称为 conv₁、conv₂、conv₃、conv₄ 和 conv₅。为了简单起见，下图仅显示了最后一个卷积层产生的张量，该张量将被转发到 SPP 层。

Figure 3. The process within the SPP layer [1].
图 3. SPP 层内部的处理过程 [1]。

Inside the SPP layer, what we do first is to divide the spatial dimension of the tensor into grids and take the maximum value within each grid — just like a typical maxpooling operation. There are 3 grid arrangements we use here: 4×4, 2×2, and 1×1, in which we will apply each of them to the same tensor. Finally, these grid cells of maximum values are flattened and concatenated, ready to be forwarded to the fully-connected part of the network.
在 SPP 层内部，我们首先要做的是将张量的空间维度划分为网格，并取每个网格内的最大值——就像典型的最大池化操作一样。这里我们使用了 3 种网格排列方式：4×4、2×2 和 1×1，我们将对同一个张量应用这三种排列。最后，这些最大值的网格单元被展平并拼接，准备转发到网络的全连接部分。

The grid arrangements are created independently of the spatial resolution of the image. This means that we will always have the same number of grid cells regardless of the input tensor shape, which also implies that at the end of the process we will obtain a fixed-length vector. Let’s take a look at the examples in Figure 4 and 5 below to prove this.
网格排列的创建与图像的空间分辨率无关。这意味着无论输入张量的形状如何，我们总是拥有相同数量的网格单元，这也意味着在处理过程结束时，我们将获得一个固定长度的向量。让我们看看下面图 4 和图 5 中的示例来证明这一点。

Figure 4. How SPP with 4×4, 2×2, and 1×1 grid arrangements works on an 8×8 feature map [2].
