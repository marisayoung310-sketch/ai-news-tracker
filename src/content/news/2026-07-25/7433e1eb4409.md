# New Portfolio!
# 全新作品集上线！

I've always loved tarot cards and readings and wanted to incorporate that aesthetic into my new portfolio. Every visual asset was designed by me in Affinity Designer, adding another design tool to my skill set alongside development.
我一直很喜欢塔罗牌及其解读，因此想将这种美学风格融入到我的新作品集中。所有的视觉素材均由我使用 Affinity Designer 设计，这让我在开发技能之外，又增添了一项设计工具。

Tech Stack Frontend: React + Vite + Custom Hooks Backend: Node.js + Express (deployed with cPanel)
技术栈：前端采用 React + Vite + 自定义 Hooks；后端采用 Node.js + Express（部署于 cPanel）。

Features:
⚫Live Spotify vinyl widget showing what I'm currently listening to (falls back to my coding playlist when I'm offline)
🟡Fan-style project carousel
Interactive constellation wheel showcasing the languages, frameworks, and tools I'm comfortable working with
⚫Contact form powered by Nodemailer + SMTP with automatic confirmation emails
🟡Form security with input sanitization, honeypot protection, and IP-based rate limiting
⚫Theme toggle for dark and light mode with little easter eggs of the zodiac constellations
功能亮点：
⚫ 实时 Spotify 黑胶唱片小组件，显示我当前正在收听的音乐（离线时会自动切换为我的编程歌单）。
🟡 扇形项目展示轮播图。
交互式星座轮盘，展示我所熟悉的编程语言、框架和工具。
⚫ 由 Nodemailer + SMTP 驱动的联系表单，支持自动发送确认邮件。
🟡 表单安全性保障，包含输入过滤、蜜罐（Honeypot）防护以及基于 IP 的速率限制。
⚫ 支持深色与浅色模式切换，并隐藏了关于黄道十二宫星座的小彩蛋。

I'm still actively tweaking and adding some minor things such as improving SEO and fine tuning layouts for different viewports! Also spent a good chunk of time debugging a multi-layer caching bug. Turns out "my API returns fresh data" and "my deployed site shows fresh data" are two very different problems once nginx, nodejs and browser fetch caching all get involved. Fun rabbit hole.
我目前仍在积极调整并添加一些细节，例如优化 SEO 以及针对不同视口微调布局！此外，我还花了不少时间调试一个多层缓存错误。事实证明，当涉及到 Nginx、Node.js 和浏览器 Fetch 缓存时，“我的 API 返回了最新数据”和“我部署的网站显示了最新数据”完全是两个不同的问题。这是一次有趣的“兔子洞”探索之旅。

I'd love to hear any feedback, and I'm always open to connecting with other developers and recruiters!
非常欢迎大家提出反馈意见，我也随时期待与各位开发者及招聘人员建立联系！
