# RustDesk now supports true unattended remote access on Wayland
# RustDesk 现已支持 Wayland 下的真正无人值守远程访问

Wayland support has been one of the harder parts of Linux remote desktop. RustDesk can now provide true unattended access on Wayland, without requiring someone at the remote machine to approve every session. Multi-monitor setups are supported as well.
Wayland 支持一直是 Linux 远程桌面领域最棘手的难题之一。RustDesk 现在可以在 Wayland 上提供真正的无人值守访问，无需远程机器端有人手动批准每次会话。此外，该功能还支持多显示器设置。

After the initial setup, you can connect even when no one is at the remote machine — including from the login screen after a reboot. Watch the demo video on X.
完成初始设置后，即使远程机器前无人值守，您也可以进行连接——包括在重启后的登录界面。请在 X (Twitter) 上观看演示视频。

For now, we are releasing this as a separate preview build for x86_64 Debian/Ubuntu-based systems: Download the Wayland unattended access build.
目前，我们针对 x86_64 架构的 Debian/Ubuntu 系统发布了一个独立的预览版本：下载 Wayland 无人值守访问版本。

Wayland support is still limited in several major remote desktop products. AnyDesk currently requires Xorg for incoming Linux sessions, while TeamViewer still describes Wayland support as experimental for common desktop environments.
目前，几款主流远程桌面产品对 Wayland 的支持仍然有限。AnyDesk 目前在 Linux 入站会话中仍要求使用 Xorg，而 TeamViewer 对常见桌面环境的 Wayland 支持仍处于实验阶段。

We would like to get more real-world testing before making this the default. Once the implementation is stable, we plan to bring unattended Wayland access to more Linux distributions, including Fedora and Arch Linux, and eventually include it in the standard RustDesk releases.
在将其设为默认功能之前，我们希望获得更多的实际测试反馈。一旦实现稳定，我们计划将 Wayland 无人值守访问功能引入更多 Linux 发行版（包括 Fedora 和 Arch Linux），并最终将其纳入 RustDesk 的标准版本中。

If you use Wayland, especially with multiple monitors, please give the preview build a try and let us know what works—and what doesn’t.
如果您正在使用 Wayland，特别是多显示器环境，请尝试此预览版本，并告诉我们哪些功能运行正常，哪些存在问题。
