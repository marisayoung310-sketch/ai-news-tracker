# From Visual Widgets to UI Code: Efficient Tool-Grounded Generation
# 从视觉组件到 UI 代码：高效的工具基础生成

**Abstract:** Existing screenshot-to-code systems face a trade-off between flexibility and controllability. Direct multimodal generation can hallucinate visible details, whereas structured pipelines reduce such errors through component-wise decomposition, predefined templates, and customized intermediate representations. These structures, however, introduce additional generative orchestration and restrict outputs to designs covered by the representation.

**摘要：** 现有的“截图转代码”系统在灵活性和可控性之间面临权衡。直接的多模态生成可能会产生视觉细节上的幻觉，而结构化流水线虽然通过组件分解、预定义模板和自定义中间表示减少了此类错误，但这些结构引入了额外的生成编排，并将输出限制在表示法所涵盖的设计范围内。

We investigate whether selective tool grounding can improve the fidelity--efficiency trade-off of direct widget-to-code generation. We introduce **WidgetGen**, a lightweight tool-grounded framework that extracts observable text and color evidence, performs high-level layout and optional chart reasoning, and directly generates executable JavaScript XML (JSX). This design reduces reliance on component-wise generation while avoiding a fixed UI schema.

我们研究了选择性工具基础（selective tool grounding）是否能改善直接从组件生成代码时的保真度与效率之间的权衡。我们引入了 **WidgetGen**，这是一个轻量级的工具基础框架，它能够提取可观察的文本和颜色证据，执行高层布局和可选的图表推理，并直接生成可执行的 JavaScript XML (JSX)。这种设计减少了对组件化生成的依赖，同时避免了固定的 UI 模式限制。

Across six multimodal models and 1,000 held-out widgets, WidgetGen outperforms direct prompting and the structured Widget2Code pipeline on most visual reconstruction metrics, with consistent gains in area, legibility, and style. Finally, reconstruction-derived image-code pairs improve six Qwen-family open-weight models across every reported metric through supervised fine-tuning. These results establish WidgetGen as a strong lightweight baseline and show that selective evidence grounding offers an effective alternative to extensive representation constraints.

在六个多模态模型和 1,000 个留存组件的测试中，WidgetGen 在大多数视觉重建指标上均优于直接提示（direct prompting）和结构化的 Widget2Code 流水线，并在区域、可读性和样式方面表现出持续的提升。最后，通过监督微调，由重建得出的图像-代码对在所有报告的指标上均提升了六个 Qwen 系列开源权重模型的效果。这些结果确立了 WidgetGen 作为一种强大的轻量级基准，并表明选择性证据基础为应对繁琐的表示约束提供了一种有效的替代方案。
