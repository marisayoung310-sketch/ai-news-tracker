# Sensitivity Analysis of GRU, LSTM and Transformer Encoder in Classification of Automated Driving Systems
# 自动驾驶系统分类中 GRU、LSTM 和 Transformer 编码器的敏感性分析

**Abstract:** Automated driving systems (ADSs) are becoming ubiquitous. Future Software Defined Vehicles (SDVs) may be able to run multiple ADSs, both native and aftermarket such as this http URL's Openpilot. Monitoring systems to independently verify which automated driving system is active are important for safety monitoring, regulatory compliance, insurance assessment, and anomaly detection.

**摘要：** 自动驾驶系统（ADS）正变得无处不在。未来的软件定义汽车（SDV）可能能够运行多种 ADS，包括原生系统和售后市场系统（如 comma.ai 的 Openpilot）。建立能够独立验证当前激活的自动驾驶系统的监控系统，对于安全监测、合规性监管、保险评估以及异常检测至关重要。

In this paper, we first evaluate the effectiveness of three sequence-based classification models: Gated Recurrent Units (GRU), Long Short-Term Memory (LSTM) networks, and a Transformer encoder model for identifying Level 2 automated driving systems using vehicle telematics data alone: Comma Openpilot, Tesla Autopilot, and Cadillac Super Cruise, along with manual driving. All three models achieve strong clean-data performance with macro F1-scores of 0.92 (GRU), 0.90 (LSTM), and 0.93 (Transformer encoder model) when trained on clean data; threat-matched training yields 0.904-0.916 macro F1 with only a modest clean-data penalty.

在本文中，我们首先评估了三种基于序列的分类模型在仅使用车辆远程信息处理数据识别 L2 级自动驾驶系统（Comma Openpilot、Tesla Autopilot、Cadillac Super Cruise 以及人工驾驶）时的有效性，这些模型包括：门控循环单元（GRU）、长短期记忆（LSTM）网络和 Transformer 编码器模型。在干净数据上训练时，这三种模型均表现出色，宏观 F1 分数分别为 0.92（GRU）、0.90（LSTM）和 0.93（Transformer 编码器）；在威胁匹配训练下，宏观 F1 分数达到 0.904-0.916，且仅有轻微的干净数据性能损失。

Second, we introduce a modular robustness evaluation framework that simulates realistic telematics degradation through five corruption families at five severity levels (L1-L5). Continuous channels are perturbed using additive white Gaussian noise with cumulative drift, correlated cross-channel noise, and temporal jitter. Binary event signals are subjected to burst loss, delayed transitions, spurious toggles and cross-feature inconsistencies inspired by communication errors.

其次，我们引入了一个模块化的鲁棒性评估框架，通过五个严重程度级别（L1-L5）的五类损坏模拟真实的远程信息处理数据退化。连续通道通过带有累积漂移的加性高斯白噪声、相关跨通道噪声和时间抖动进行扰动。二进制事件信号则受到受通信错误启发的突发丢失、延迟转换、虚假切换和跨特征不一致性的影响。

Robustness is measured using macro-F1, which gives equal weight to each class and is suitable for imbalanced multiclass evaluation. Our evaluation reveals a sharp failure-mode split: event-level corruptions reduce macro-F1 only slightly (greater than equal to 0.87 at L5), while temporal jitter collapses macro-F1 to 0.44-0.50 across GRU, LSTM, and Transformer encoder model.

鲁棒性通过宏观 F1 分数进行衡量，该指标对每个类别赋予相同的权重，适用于不平衡的多类评估。我们的评估揭示了明显的故障模式差异：事件级损坏仅轻微降低了宏观 F1 分数（在 L5 级别下仍大于等于 0.87），而时间抖动则导致 GRU、LSTM 和 Transformer 编码器模型的宏观 F1 分数大幅下降至 0.44-0.50。
