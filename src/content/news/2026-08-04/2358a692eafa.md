# LARA: Lightweight Adapters in the Residual Stream for Composable Adaptation and Alignment
# LARA：用于可组合适应与对齐的残差流轻量级适配器

**Abstract:** We present LARA (Lightweight Additive Residual Adaptation), a method for efficient adaptation that operates in the residual stream of a frozen model rather than in its weights. 
**摘要：** 我们提出了 LARA（轻量级加性残差适应），这是一种高效的适应方法，它在冻结模型的残差流中运行，而不是在权重中进行操作。

Where LoRA adds an update of low rank to weight matrices, LARA reads the hidden state at a small set of layers and adds a correction of low rank back to the residual stream, leaving all base weights untouched. 
与 LoRA 在权重矩阵中添加低秩更新不同，LARA 通过读取少量层中的隐藏状态，并将低秩修正添加回残差流中，从而保持所有基础权重不变。

On a code fine-tuning task and on preference optimization (DPO), LARA matches LoRA at equal parameter counts. 
在代码微调任务和偏好优化（DPO）任务中，LARA 在参数量相等的情况下表现与 LoRA 持平。

Because adaptation is a frozen base plus a residual, LARA exposes a scale {\gamma}, applied at inference, that interpolates smoothly between base and adapted behavior, a form of graded control that adaptation in weight space does not offer. 
由于该适应方法是“冻结基础模型 + 残差”的结构，LARA 在推理时引入了一个缩放因子 {\gamma}，可以在基础行为和适应后的行为之间进行平滑插值，这是一种在权重空间进行适应时无法实现的渐进式控制。

Finally, because each behavior is a small residual module over a shared frozen base, many behaviors can be held resident at once and routed automatically per token. 
最后，由于每种行为都是基于共享冻结基础上的小型残差模块，因此可以同时驻留多种行为，并按 Token 自动路由。

We place seven behaviors, six fine-tuned and one optimized for preference, on one frozen 1.5B model for roughly 33 MB of overhead, against one full model for each behavior. 
我们将七种行为（六种微调行为和一种偏好优化行为）部署在一个冻结的 1.5B 模型上，仅需约 33 MB 的额外开销，而若为每种行为加载一个完整模型则开销巨大。

Because the base is untouched, behaviors are trained separately and selected per token rather than loaded on demand, which suits hosting many behaviors, and adding new ones, on a single model on a device.
由于基础模型未被改动，各种行为可以独立训练并按 Token 选择，无需按需加载，这非常适合在设备上的单一模型中托管多种行为并随时添加新行为。
