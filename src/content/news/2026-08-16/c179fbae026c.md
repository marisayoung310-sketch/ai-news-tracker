# Firefox is now the last major browser that still supports uBlock Origin
# Firefox 现已成为唯一仍支持 uBlock Origin 的主流浏览器

Firefox recently announced via Bluesky post: “Our support for uBlock Origin isn’t going anywhere.” The moment comes in response to news that Microsoft Edge is soon going to lock out uBlock Origin and other ad-blocking extensions that run on Manifest V2 architecture.
Firefox 最近通过 Bluesky 发帖宣布：“我们对 uBlock Origin 的支持不会有任何改变。” 此举是为了回应近期的一则消息：Microsoft Edge 即将封锁 uBlock Origin 以及其他基于 Manifest V2 架构运行的广告拦截扩展程序。

Once Microsoft Edge moves to Manifest V3, ad-blocking extensions won’t have access to the functions needed to properly identify and block ads that occur while browsing websites and watching videos. Microsoft’s move isn’t surprising, as Edge is based on Chromium, the open-source browser engine that powers most web browsers today, including Opera, Brave, Vivaldi, and Samsung Browser. Google initiated the migration from Manifest V3 in Chrome/Chromium, and Microsoft Edge is now following Google’s lead.
一旦 Microsoft Edge 迁移至 Manifest V3，广告拦截扩展程序将无法访问必要的函数，从而无法在用户浏览网页或观看视频时准确识别并拦截广告。微软的这一举动并不令人意外，因为 Edge 基于 Chromium 构建——这是目前大多数网页浏览器（包括 Opera、Brave、Vivaldi 和三星浏览器）所采用的开源浏览器引擎。谷歌率先在 Chrome/Chromium 中启动了从 Manifest V2 到 V3 的迁移，而 Microsoft Edge 现在正紧随其后。

But Firefox is one of the few web browsers remaining that isn’t based on Chromium, and it’s now the only major browser to still support uBlock Origin. Neither Safari nor DuckDuckGo—the two other major non-Chromium browsers out there—support uBlock Origin.
但 Firefox 是目前为数不多不基于 Chromium 的网页浏览器之一，现在它也是唯一仍支持 uBlock Origin 的主流浏览器。Safari 和 DuckDuckGo 这另外两款主流的非 Chromium 浏览器均不支持 uBlock Origin。

For die-hard uBlock Origin fans, Firefox appears to be the only browser left without compromises. With any other browser, you’ll need to settle for uBlock Origin Lite (with fewer features and less ad-blocking success) or whatever built-in ad-blocking feature comes with the browser.
对于 uBlock Origin 的忠实拥趸来说，Firefox 似乎是唯一无需妥协的选择。使用其他任何浏览器，你都只能退而求其次选择 uBlock Origin Lite（功能较少，广告拦截效果也较弱），或者使用浏览器自带的广告拦截功能。
