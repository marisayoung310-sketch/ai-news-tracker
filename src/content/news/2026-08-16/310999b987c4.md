### What is SysPeek?
### 什么是 SysPeek？

SysPeek is a modern desktop application that allows you to inspect your computer's hardware and monitor live system performance from a single interface. ### Security First
### 安全至上

Desktop applications often overlook security. SysPeek follows Electron's recommended security practices: Context Isolation enabled, Sandbox enabled, Node Integration disabled, Secure preload bridge, Typed IPC communication, Strict Content Security Policy, and Whitelisted API exposure. System information is collected only in the Electron main process, while the React interface communicates through a carefully controlled IPC bridge.
桌面应用程序往往忽视安全性。SysPeek 遵循 Electron 推荐的安全实践：启用上下文隔离、启用沙盒、禁用 Node 集成、安全的预加载桥接、类型化的 IPC 通信、严格的内容安全策略以及白名单 API 暴露。系统信息仅在 Electron 主进程中收集，而 React 界面则通过严格控制的 IPC 桥接进行通信。

### Getting Started
### 快速开始

Clone the repository and install dependencies:
克隆仓库并安装依赖：

```bash
git clone https://github.com/shehari007/SysPeek-hwinfo-react-electron-app.git
cd SysPeek-hwinfo-react-electron-app
npm install
npm run dev
```

The development server launches Electron with hot reload for both the renderer and the main process.
开发服务器将启动 Electron，并为渲染进程和主进程提供热重载功能。
