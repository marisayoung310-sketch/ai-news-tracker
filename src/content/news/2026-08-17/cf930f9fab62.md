# Claude: System Prompts (Claude：系统提示词)

Claude's web interface (claude.ai) and mobile apps use a system prompt to provide up-to-date information, such as the current date, to Claude at the start of every conversation.
Claude 的网页界面 (claude.ai) 和移动应用程序使用系统提示词，在每次对话开始时为 Claude 提供最新信息（例如当前日期）。

The system prompt also encourages certain behaviors, such as always providing code snippets in Markdown. This prompt is periodically updated to improve Claude's responses.
系统提示词还会引导特定的行为，例如要求始终以 Markdown 格式提供代码片段。该提示词会定期更新，以改善 Claude 的回复质量。

These system prompt updates do not apply to the Claude API. Where a model has multiple dated entries below, updates between versions are bolded. Starting with the Claude 4.6 generation, each model ID is a single fixed snapshot, so those models have one entry.
这些系统提示词的更新不适用于 Claude API。在下方模型拥有多个日期条目的情况下，版本间的更新内容已加粗显示。从 Claude 4.6 版本开始，每个模型 ID 均为单一的固定快照，因此这些模型仅有一个条目。
