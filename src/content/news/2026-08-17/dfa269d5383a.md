### Firefox for iOS now has a native adblocker
### Firefox iOS 版现已内置原生广告拦截器

Mozilla has officially updated its Firefox browser for iOS, introducing a built-in ad-blocking feature designed to improve page load speeds and reduce data consumption.
Mozilla 已正式更新其 iOS 版 Firefox 浏览器，引入了内置的广告拦截功能，旨在提高页面加载速度并减少数据消耗。

This new native tool allows users to block trackers and intrusive advertisements directly within the browser settings, eliminating the need for third-party extensions.
这一全新的原生工具允许用户直接在浏览器设置中拦截追踪器和侵入式广告，无需再依赖第三方扩展程序。

By blocking these elements, Firefox aims to provide a cleaner, faster, and more private browsing experience for iPhone and iPad users.
通过拦截这些元素，Firefox 旨在为 iPhone 和 iPad 用户提供更简洁、更快速且更具隐私性的浏览体验。

Users can enable or disable this feature at any time through the "Tracking Protection" menu located in the browser's settings panel.
用户可以随时通过浏览器设置面板中的“跟踪保护”（Tracking Protection）菜单来开启或关闭此功能。
