# UserToolBench: A User-Profile-Hidden Benchmark for Personalized Decision Making in Tool-Use LLMs
# UserToolBench：一个用于工具使用大模型个性化决策的隐藏用户画像基准测试

**Abstract:** Tool-use LLMs are increasingly asked to act on users' behalf, but existing benchmarks usually focus on profile recall, style imitation, generic tool use, or response-level personalization. We introduce UserToolBench, a benchmark for personalized decision making in tool-use LLMs.

**摘要：** 工具使用大模型（Tool-use LLMs）越来越多地被要求代表用户执行任务，但现有的基准测试通常侧重于画像回忆、风格模仿、通用工具使用或响应层面的个性化。我们引入了 UserToolBench，这是一个用于评估工具使用大模型个性化决策能力的基准测试。

UserToolBench tests whether a model can infer latent user preferences from interaction history, recognize when clarification is needed, and produce user-aligned tool-call trajectories under incomplete information. The benchmark is built from privacy-sanitized real interaction traces and combines structured persona profiles, public API-style tool ecosystems, and long-horizon multi-turn trajectories.

UserToolBench 测试模型是否能够从交互历史中推断潜在的用户偏好，识别何时需要澄清，并在信息不完整的情况下生成符合用户意图的工具调用轨迹。该基准测试基于经过隐私脱敏的真实交互记录构建，结合了结构化的人格画像、公共 API 风格的工具生态系统以及长周期的多轮交互轨迹。

It includes 10 user profiles, 36 tool sets, 1,065 turns, 170 unique tools, and evaluation-focused task types covering lack-of-information, single-tool, and multi-tool settings. Experiments with strong tool-use LLMs show that current models still have difficulty with personalized delegation. Multi-tool coordination, missing-constraint inference, and long-horizon behavioral consistency remain major bottlenecks.

它包含 10 个用户画像、36 个工具集、1,065 轮对话、170 个独立工具，以及涵盖信息缺失、单工具和多工具设置的评估导向型任务类型。对主流强力工具使用大模型的实验表明，当前模型在个性化委托方面仍存在困难。多工具协调、缺失约束推理以及长周期行为一致性仍然是主要瓶颈。

These results suggest that personalization evaluation should move beyond asking whether outputs sound user-specific and instead ask whether LLMs make correct decisions for the users they represent.

这些结果表明，个性化评估应超越“输出听起来是否具有用户特征”的层面，转而关注大模型是否能为其所代表的用户做出正确的决策。
