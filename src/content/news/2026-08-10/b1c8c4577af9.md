# Building LoanAI: AI-Powered Loan Default Prediction System using Flask & Scikit-Learn
# 构建 LoanAI：基于 Flask 和 Scikit-Learn 的 AI 贷款违约预测系统

Hi everyone! 👋 I recently developed LoanAI, a real-time credit risk assessment platform that predicts loan default probabilities using machine learning models.
大家好！👋 我最近开发了 LoanAI，这是一个利用机器学习模型来预测贷款违约概率的实时信用风险评估平台。

### Key Features
### 核心功能

**Instant Risk Scoring:** Real-time credit risk assessment for loan applicants.
**即时风险评分：** 为贷款申请人提供实时信用风险评估。

**Explainable AI:** Transparent prediction logic for financial decision-making.
**可解释的 AI：** 为金融决策提供透明的预测逻辑。

**Clean UI:** Built with Flask, Bootstrap 5, and Python.
**简洁的界面：** 使用 Flask、Bootstrap 5 和 Python 构建。
