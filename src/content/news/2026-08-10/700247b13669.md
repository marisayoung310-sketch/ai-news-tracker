# Anthropic is turning Claude Code’s auto mode on by default
# Anthropic 将默认开启 Claude Code 的自动模式

**Anthropic is turning Claude Code’s auto mode on by default**
**Anthropic 将默认开启 Claude Code 的自动模式**

Programming with Claude Code will soon require even less human oversight, as Anthropic says it’s making auto mode the default for Pro, Max, and Team accounts, starting on August 14.
使用 Claude Code 进行编程将很快需要更少的人工监督，因为 Anthropic 表示，从 8 月 14 日起，它将把自动模式设为 Pro、Max 和 Team 账户的默认设置。

The company first unveiled a test version of auto mode in March, pitching it as a way to balance speed and control.
该公司于今年 3 月首次发布了自动模式的测试版本，并将其作为平衡速度与控制力的一种方式进行推广。

As Anthropic explained in its announcement on Friday, when Claude Code is in auto mode, instead of presenting prompts asking for human approval at each step, it will proceed unless an action is determined to be “irreversible, destructive, or aimed outside your environment.”
正如 Anthropic 在周五的公告中所解释的那样，当 Claude Code 处于自动模式时，它不会在每一步都弹出提示请求人工批准，而是会直接执行，除非该操作被判定为“不可逆、具有破坏性或针对环境之外的目标”。

Anthropic also said that in testing, auto mode proved safer than manual review — in a study with 1,053 paid testers, auto mode caught 89% of harmful actions, while human review only caught 13.6%. (Perhaps that’s because “manual review can become habitual: users approve 97% of permission prompts in Claude Code.”)
Anthropic 还表示，在测试中，自动模式被证明比人工审核更安全——在一项针对 1,053 名付费测试者的研究中，自动模式捕获了 89% 的有害操作，而人工审核仅捕获了 13.6%。（这可能是因为“人工审核容易流于形式：用户在 Claude Code 中批准了 97% 的权限提示”。）

In a post on X, Claude Code Head Boris Cherny said, “The team and I use Auto mode exclusively, and have been for many months. I couldn’t imagine going back to permission prompts!”
Claude Code 负责人 Boris Cherny 在 X 上发文称：“我和团队一直都在专门使用自动模式，并且已经使用了好几个月。我无法想象再回到需要手动确认权限的模式！”

The company also said it’s been adding new safety features like prompt injection screening and customizable hard deny rules to prevent things like data exfiltration.
该公司还表示，他们一直在增加新的安全功能，例如提示词注入（prompt injection）筛选和可自定义的强制拒绝规则，以防止数据泄露等问题。
