# An Explainable LLM Agent Layer for Open-World Anomaly Detection in Oil Wells
# 用于油井开放世界异常检测的可解释大模型代理层

**Abstract:** Open-World Learning (OWL) pipelines for oil well anomaly detection have recently been shown to combine autoencoder-based detection, multiclass classification, and Mahalanobis-based novelty detection on the public 3W dataset. These pipelines answer *what happened*, but they do not explain *why the model believes it* or *what the operator should do next*, and they do not put a human-readable name on the novelty clusters they discover.

**摘要：** 近期研究表明，用于油井异常检测的开放世界学习（OWL）流水线结合了基于自动编码器的检测、多类分类以及基于马氏距离的新颖性检测，并已在公开的 3W 数据集上进行了验证。这些流水线能够回答“发生了什么”，但无法解释“模型为何做出此判断”或“操作员下一步该做什么”，也无法为发现的新颖性聚类提供人类可读的命名。

This paper evaluates a Large Language Model (LLM) agent layer placed downstream of the OWL pipeline, designed as a **companion** to the published upstream methods rather than a replacement. Using the Qwen3.5-397B-A17B Mixture-of-Experts model served via NVIDIA NIM, the agent receives structured sensor metrics and upstream classification or novelty assertions, and returns natural-language justifications, confidence-ranked critiques, and consolidated names for detected novelties.

本文评估了一个置于 OWL 流水线下游的大语言模型（LLM）代理层，其设计初衷是作为现有上游方法的**配套工具**，而非替代品。该代理利用通过 NVIDIA NIM 部署的 Qwen3.5-397B-A17B 混合专家模型（MoE），接收结构化的传感器指标以及上游的分类或新颖性断言，并返回自然语言形式的论证、置信度排序的评估意见，以及对检测到的新颖性事件的统一命名。

Across three studies spanning 989 real well-file segments from the 3W dataset, the agent achieved 35.1% top-1 / 63.9% top-3 (95% CI [56.9, 70.4]) classification on all nine classes, 71.7% top-2 validation [64.8, 77.6] with precision 0.91 [0.84, 0.95] across 7 probed classes, and 89.7% novelty detection [87.0, 91.9] with stable cluster naming on 5 of 7 hidden classes.

在涵盖 3W 数据集中 989 个真实油井文件片段的三项研究中，该代理在所有九个类别上的分类准确率达到 35.1% (Top-1) / 63.9% (Top-3)（95% 置信区间 [56.9, 70.4]）；在 7 个探测类别上的 Top-2 验证准确率为 71.7% [64.8, 77.6]，精确度为 0.91 [0.84, 0.95]；在新颖性检测方面达到 89.7% [87.0, 91.9]，并成功为 7 个隐藏类别中的 5 个实现了稳定的聚类命名。

The agent is not a standalone classifier. Its role is to: (1) confirm upstream decisions when sensor evidence supports them, (2) justify decisions in sensor-grounded language operators can audit, (3) flag disagreement when upstream labels are implausible, and (4) name novelties so that clustered unlabeled events arrive at the engineer with a consolidated human-readable label. The goal is to close the explainability gap that currently blocks deployment of OWL pipelines in operational settings.

该代理并非独立的分类器。其作用在于：(1) 当传感器证据支持时确认上游决策；(2) 以操作员可审计的、基于传感器数据的语言来论证决策；(3) 当上游标签不可信时标记分歧；(4) 对新颖性事件进行命名，以便将聚类后的未标记事件以统一的人类可读标签呈现给工程师。其目标是弥合当前阻碍 OWL 流水线在实际生产环境中部署的可解释性鸿沟。
