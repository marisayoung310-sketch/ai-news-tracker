# RUTA: Principled Visual Token Allocation via Rate-Utility Optimization
# RUTA：基于速率-效用优化的原则性视觉 Token 分配方法

High-resolution images and long videos provide vision-language models with rich context for multimodal reasoning and fine-grained perception, but the resulting long visual token sequences make large language model-side computation and memory costly.
高分辨率图像和长视频为视觉语言模型提供了丰富的上下文，以进行多模态推理和细粒度感知，但由此产生的长视觉 Token 序列导致大语言模型端的计算和内存成本高昂。

Existing visual token reducers often operate at prescribed rates, while recent methods adapt token counts across inputs using method-specific learned thresholds or importance predictors.
现有的视觉 Token 缩减器通常在预设的速率下运行，而近期的一些方法则通过特定于方法的学习阈值或重要性预测器来调整不同输入下的 Token 数量。

We introduce RUTA, a principled Rate-Utility Token Allocation method that performs pre-LLM reduction by jointly learning which tokens to retain and how many to allocate to each image-query pair.
我们引入了 RUTA，这是一种原则性的“速率-效用 Token 分配”方法。它通过联合学习保留哪些 Token 以及为每个图像-查询对分配多少 Token，在进入大语言模型（LLM）之前执行缩减操作。

RUTA constructs query-conditioned candidate tokens and predicts a retention probability for each candidate. During training, these probabilities parameterize independent Bernoulli gates, while their sum provides a differentiable training-time estimate of the token count for each pair.
RUTA 构建了以查询为条件的候选 Token，并为每个候选者预测保留概率。在训练过程中，这些概率参数化了独立的伯努利门（Bernoulli gates），而它们的总和为每个图像-查询对的 Token 数量提供了一个可微分的训练时估计。

Retained tokens serve as anchors that aggregate information from non-retained tokens according to semantic affinity and spatial proximity. RUTA is optimized with a penalized rate-utility objective that balances downstream task loss against expected token usage.
被保留的 Token 作为锚点，根据语义亲和力和空间邻近度聚合来自未保留 Token 的信息。RUTA 通过一种带惩罚的速率-效用目标函数进行优化，该函数平衡了下游任务损失与预期的 Token 使用量。

Averaged across five benchmarks and measured relative to each backbone's full-token baseline, RUTA uses only 2.0% and 4.2% of visual tokens while preserving 88.2% and 94.4% of task performance on LLaVA-NeXT-7B and Qwen3-VL-8B, respectively.
在五个基准测试的平均值中，相对于每个主干模型的全 Token 基准，RUTA 在 LLaVA-NeXT-7B 和 Qwen3-VL-8B 上分别仅使用了 2.0% 和 4.2% 的视觉 Token，同时保留了 88.2% 和 94.4% 的任务性能。
