# GitHub Actions and Pages are experiencing degraded availability
# GitHub Actions 和 Pages 服务出现可用性下降

***

**Update:** We’re investigating reports that some Actions Runner Controller runners are taking longer than expected to recover. We’ll provide an update as our investigation progresses.
Posted Aug 07, 2026 - 00:59 UTC

**更新：** 我们正在调查有关部分 Actions Runner Controller 运行器恢复时间超出预期的报告。随着调查的进展，我们将提供进一步更新。
发布时间：2026年8月7日 - 00:59 UTC

***

**Monitoring:** The degradation has been mitigated. We are monitoring to ensure stability.
Posted Aug 07, 2026 - 00:06 UTC

**监控中：** 服务降级问题已得到缓解。我们正在进行监控以确保系统稳定性。
发布时间：2026年8月7日 - 00:06 UTC

***

**Update:** The degradation affecting Actions and Pages has been mitigated. We are monitoring to ensure stability.
Posted Aug 07, 2026 - 00:05 UTC

**更新：** 影响 Actions 和 Pages 的服务降级问题已得到缓解。我们正在进行监控以确保系统稳定性。
发布时间：2026年8月7日 - 00:05 UTC

***

**Update:** System-wide queues have been drained, and new jobs are being processed as expected. The fix for self-hosted runners not picking up jobs has been fully rolled out. Webhook-triggered Actions workflows have been restored to full throughput. GitHub Pages, Copilot code review, and Copilot coding agent are showing recovery. Migrations using GitHub Enterprise Importer remain paused as a precaution. We are monitoring all affected services for sustained recovery and will provide another update shortly.
Posted Aug 07, 2026 - 00:01 UTC

**更新：** 系统级队列已清空，新任务正按预期处理。针对自托管运行器无法获取任务的修复程序已全面部署。由 Webhook 触发的 Actions 工作流已恢复至正常吞吐量。GitHub Pages、Copilot 代码审查和 Copilot 编码代理功能正在恢复中。出于预防措施，使用 GitHub Enterprise Importer 进行的迁移任务仍处于暂停状态。我们正在监控所有受影响的服务以确保其持续恢复，并将很快提供进一步更新。
发布时间：2026年8月7日 - 00:01 UTC
