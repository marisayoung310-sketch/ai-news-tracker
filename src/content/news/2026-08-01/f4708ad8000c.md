# VideoCoCo: Code-as-CoT for Physically-Consistent Video Generation via an Agentic Dual-Engine System
# VideoCoCo：通过智能体双引擎系统实现物理一致性视频生成的“代码即思维链”方法

**Abstract:** Text-to-video models have achieved remarkable visual quality, yet they still struggle to generate physically consistent dynamics because the temporal evolution of a scene must be inferred implicitly from a highly compressed text prompt. Existing chain-of-thought approaches introduce intermediate plans or visual states, but these representations are typically non-executable or temporally sparse, limiting their ability to instantiate and control the complete spatiotemporal process.

**摘要：** 文本生成视频模型虽然已经实现了卓越的视觉质量，但在生成物理一致的动态效果方面仍面临挑战，因为场景的时间演变必须从高度压缩的文本提示中隐式推断出来。现有的思维链（Chain-of-Thought）方法引入了中间计划或视觉状态，但这些表示通常是不可执行的或在时间上稀疏的，从而限制了它们实例化和控制完整时空过程的能力。

To address this limitation, we introduce VideoCoCo, an agentic dual-engine framework in which executable Blender code serves as a process-level chain of thought. Given a text prompt, a coding agent synthesizes a Blender program that explicitly specifies the scene and its temporal evolution. The executable simulation engine runs the program to produce a deterministic spatiotemporal draft, which is subsequently transformed into a photorealistic video by a generative video engine through draft-conditioned editing. This decomposition separates process-level reasoning from high-fidelity visual realization.

为了解决这一局限性，我们引入了 VideoCoCo，这是一个智能体双引擎框架，其中可执行的 Blender 代码充当了过程级的思维链。给定一个文本提示，编码智能体会合成一个 Blender 程序，明确指定场景及其时间演变。可执行的模拟引擎运行该程序以生成确定性的时空草图，随后由生成式视频引擎通过草图条件编辑将其转换为照片级逼真的视频。这种分解将过程级推理与高保真视觉实现分离开来。

To adapt the video editor to simulated drafts, we construct VideoCoCo-3K, a curated dataset of draft-instruction-target triplets. VideoCoCo improves the OmniWeaving baseline from 0.475 to 0.558 on PhyGenBench and from 52.18 to 77.88 on VBench-2.0, achieving the best average score on both benchmarks. These results demonstrate that executable code provides an effective, controllable, and inspectable intermediate representation for physically consistent video generation.

为了使视频编辑器适应模拟草图，我们构建了 VideoCoCo-3K，这是一个包含草图-指令-目标三元组的精选数据集。VideoCoCo 将 OmniWeaving 基准在 PhyGenBench 上的得分从 0.475 提升至 0.558，在 VBench-2.0 上的得分从 52.18 提升至 77.88，在两个基准测试中均取得了最佳平均分。这些结果表明，可执行代码为物理一致的视频生成提供了一种有效、可控且可检查的中间表示形式。
