# Pepper Remastered coming soon
# Pepper Remastered 即将推出

I've decided to create a more feature-rich version of Pepper, an experimental virtual VR device that allows you to use SteamVR without requiring a physical VR headset or controllers. Using only a keyboard and mouse, Pepper creates a fake VR device that SteamVR recognizes, allowing you to play supported VR games from your Steam library.
我决定为 Pepper 开发一个功能更丰富的版本。Pepper 是一款实验性的虚拟 VR 设备，它让你无需物理 VR 头显或控制器即可使用 SteamVR。仅通过键盘和鼠标，Pepper 就能创建一个 SteamVR 可识别的虚拟 VR 设备，让你能够游玩 Steam 库中支持的 VR 游戏。

The original Pepper that I made a few months ago was a small proof-of-concept showing that it was possible to create a software-only VR device using SteamVR's driver system. While it worked, it was limited and required a lot of manual setup. Pepper Remastered aims to rebuild the project with a stronger foundation, better usability, and more features.
几个月前我制作的初代 Pepper 只是一个小型的概念验证，旨在展示利用 SteamVR 驱动系统创建纯软件 VR 设备的可行性。虽然它确实能用，但功能有限且需要大量手动设置。Pepper Remastered 旨在通过更坚实的基础、更好的易用性和更多功能来重构该项目。
