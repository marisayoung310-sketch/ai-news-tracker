# Reddit is introducing a new moderator: AI
# Reddit 引入了一位新版主：人工智能

Reddit is enlisting AI to help moderate new subreddits — and eventually the rest of site. The company is introducing automated moderation tools that rely on LLMs to help mods manage their communities, and it’s expanding who can use those tools today ahead of a full launch later this year.

Reddit 正在引入人工智能来协助管理新的子版块（subreddits），并最终覆盖整个网站。该公司正在推出依赖大语言模型（LLM）的自动化管理工具，以帮助版主管理社区。在今年晚些时候全面发布之前，Reddit 今天扩大了这些工具的使用范围。

The company calls the suite of tools “Rules Hub,” and the tools let mods decide what rules should be automatically enforced and what should happen when a rule is triggered. Rules Hub relies on LLMs to evaluate “whether a post or comment matches the intent of a rule,” which “allows Rules Hub to better handle nuance, natural language, and edge cases while preserving moderator control,” Reddit says in a blog post. Right now, many subreddits use tools from a feature called Automoderator (aka Automod) to take action on rules, but Automod’s tools “depend on exact keyword and pattern matching.”

该公司将这套工具称为“规则中心”（Rules Hub），它允许版主决定哪些规则应自动执行，以及触发规则时应采取什么行动。Reddit 在一篇博客文章中表示，Rules Hub 依靠大语言模型来评估“帖子或评论是否符合规则的意图”，这“使 Rules Hub 能够在保持版主控制权的同时，更好地处理细微差别、自然语言和边缘情况”。目前，许多子版块使用名为 Automoderator（简称 Automod）的功能来执行规则，但 Automod 的工具“依赖于精确的关键词和模式匹配”。

Reddit says that Rules Hub has been in testing for “the past few months” with “new and experienced moderators from over 700 communities, including members of Reddit’s Mod Council Network.” That test of Rules Hub is now expanding to “all newly created communities” and will be “widely available” at some point later in 2026.

Reddit 表示，Rules Hub 在“过去几个月”里一直在进行测试，参与者包括“来自 700 多个社区的新老版主，以及 Reddit 版主委员会网络的成员”。目前，Rules Hub 的测试范围正在扩大到“所有新创建的社区”，并将于 2026 年晚些时候“广泛发布”。

Rules Hub will be optional for new communities, spokesperson Rosa Kim tells The Verge. However, it does sound as if Reddit plans to retire Automod’s enforcement features down the line: In its post, Reddit says that “Looking ahead, we believe Rules Hub, together with newer systems like Post & Comment Guidance and Safety Filters, can eventually replace many of the enforcement workflows that communities rely on from Automod,” Reddit says in its post.

Reddit 发言人 Rosa Kim 告诉 The Verge，Rules Hub 对新社区而言是可选的。然而，听起来 Reddit 确实计划在未来逐步淘汰 Automod 的执行功能：Reddit 在文章中表示：“展望未来，我们相信 Rules Hub 以及‘帖子与评论指南’（Post & Comment Guidance）和‘安全过滤器’（Safety Filters）等较新的系统，最终可以取代社区目前依赖 Automod 执行的许多工作流程。”

“We can do better.”
“我们可以做得更好。”

Automod has been “one of the most important mod tools,” Reddit CEO Steve Huffman says in a post. “But it’s also hard to learn, hard to maintain, and heavily dependent on brittle keyword matching, regex, and inherited configurations that only a few people on a mod team, if any, understand. We can do better.”

Reddit 首席执行官 Steve Huffman 在文章中表示，Automod 一直是“最重要的版主工具之一”。“但它也很难学习、难以维护，并且严重依赖脆弱的关键词匹配、正则表达式以及继承的配置，而这些配置只有版主团队中的少数人（如果有的话）才能理解。我们可以做得更好。”

The updated mod tools are just one of a few big platform announcements Reddit is making on Wednesday. The company is also planning big changes that will affect developers: It’s going to require new third-party apps to use the developer platform instead of the API.

更新后的版主工具只是 Reddit 周三宣布的几项重大平台公告之一。该公司还计划进行影响开发者的重大变革：它将要求新的第三方应用程序使用开发者平台，而不是直接使用 API。

“We envision a future where all good, trusted automation on Reddit runs within an ecosystem that allows us to offer support and enforce our policies consistently,” Reddit says. “To achieve this, we will continue supporting limited public API access, but we will gradually restrict new requests and require third-party apps to transition to and operate on Reddit’s Developer Platform.”

“我们设想的未来是，Reddit 上所有良好、可信的自动化程序都在一个生态系统中运行，使我们能够提供支持并始终如一地执行我们的政策，”Reddit 表示。“为了实现这一目标，我们将继续支持有限的公共 API 访问，但我们将逐步限制新的请求，并要求第三方应用程序迁移到 Reddit 的开发者平台并在此基础上运行。”

“Reddit’s public API wasn’t designed for today’s scale, automated abuse, or commercial scraping,” Huffman says. “We want useful bots, community tools, and good-faith developers to have a clear, well-supported way to build on Reddit. We don’t want bad actors to scrape Reddit indiscriminately, resell its data, or use it without accountability.”

“Reddit 的公共 API 并非为当今的规模、自动化滥用或商业抓取而设计，”Huffman 说。“我们希望有用的机器人、社区工具和诚信的开发者能够拥有清晰、受支持的方式在 Reddit 上进行构建。我们不希望不良行为者肆意抓取 Reddit、转售其数据或在没有问责的情况下使用它。”

The shift follows Reddit’s major API changes in 2023 that it put in place to get AI companies to pony up for Reddit’s data but also caused widespread backlash in part because they forced many beloved Reddit apps to shut down. Currently, if a developer wants to make a Reddit mobile app, they have to get permission from Reddit to get public API exemptions, and that will continue to be the case, Kim says.

此举继 Reddit 2023 年重大的 API 变更之后。当时 Reddit 旨在让 AI 公司为其数据付费，但也引发了广泛的抵制，部分原因是这些变更迫使许多广受欢迎的 Reddit 应用程序关闭。Kim 表示，目前如果开发者想要制作 Reddit 移动应用，他们必须获得 Reddit 的许可才能获得公共 API 的豁免权，这种情况未来将继续保持。

Reddit doesn’t have a “set timeline” yet for requiring the developer platform, but the company will give “give the community ample notice” and provide a clear timeline, Kim says. The upcoming change will affect “all API apps except the ones we explicitly grant exceptions to,” according to Kim.

Kim 表示，Reddit 尚未为强制使用开发者平台设定“明确的时间表”，但公司会“给予社区充分的通知”并提供明确的时间表。据 Kim 称，即将到来的变化将影响“除我们明确授予豁免权之外的所有 API 应用程序”。

“In order to protect our platform, business, and users, we will need to do something.”
“为了保护我们的平台、业务和用户，我们需要采取行动。”

Reddit is also saying today that it’s planning more changes to old Reddit as part of its ongoing efforts to fight unauthorized scraping of its content. Those efforts already include blocking Reddit results from search engines that don’t pay, suing Anthropic and Perplexity, and blocking the Internet Archive to stop AI companies from using it to scrape data, and in June, the company announced that people would have to be logged in if they wanted to use the old Reddit interface.

Reddit 今天还表示，作为打击未经授权的内容抓取工作的一部分，它计划对“旧版 Reddit”（old Reddit）进行更多更改。这些努力已经包括阻止不付费的搜索引擎抓取 Reddit 结果、起诉 Anthropic 和 Perplexity，以及阻止 Internet Archive 以防止 AI 公司利用其抓取数据。今年 6 月，该公司还宣布，用户必须登录才能使用旧版 Reddit 界面。

Reddit doesn’t specify what the changes to old Reddit will be, but Kim says the company is “exploring different options” and notes that “in the short term we will limit access to logged-in users and migrate critical bots and moderator workflows.”

Reddit 没有具体说明对旧版 Reddit 的更改内容，但 Kim 表示公司正在“探索不同的方案”，并指出“短期内我们将限制访问权限，仅限登录用户，并迁移关键的机器人和版主工作流程。”

“In order to protect our platform, business, and users, we will need to do something” with old Reddit, Huffman says. “Actually, a lot of somethings. We have options: We can limit access, migrate important uses, or rebuild it on a modern tech stack, and I think we’ll probably do all of the above.”

“为了保护我们的平台、业务和用户，我们需要对旧版 Reddit 采取一些行动，”Huffman 说。“实际上，是很多行动。我们有多种选择：我们可以限制访问、迁移重要用途，或者在现代技术栈上重建它，我认为我们可能会采取上述所有措施。”

Huffman also acknowledges that users may be wary of big changes. “We know announcements about APIs and legacy products come with some baggage,” he says. “‘Trust us’ isn’t good enough. If we’re asking you to move to something new, it has to be at parity or better in practice, not just in theory.” He says that Reddit won’t “remove major capabilities before there is a credible replacement,” will work with mods, developers, and communities affected, and will “share milestones along the way before any of these changes land.”

Huffman 也承认用户可能对重大变革持谨慎态度。“我们知道关于 API 和旧产品的公告会带来一些负面影响，”他说。“‘相信我们’是不够的。如果我们要求你们转向新事物，它在实践中必须达到或优于现有水平，而不仅仅是在理论上。”他表示，Reddit 不会在“有可靠的替代方案之前移除主要功能”，并将与受影响的版主、开发者和社区合作，并在“任何这些变更落地之前分享沿途的里程碑”。
