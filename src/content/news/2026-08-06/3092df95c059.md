# Introduction to Semi-Supervised Learning
# 半监督学习入门

A primer about Semi-Supervised Learning, the approaches taken with different algorithms and the limitations of using unlabelled data.
这是一篇关于半监督学习的入门指南，介绍了不同算法所采用的方法以及使用未标记数据时的局限性。

When you think about a Machine Learning method that solves a Classification problem, i.e., when you have to determine the class or category of a specific data point, it’s likely that you’ll think about gathering a training dataset where every single data point is labeled with its corresponding class. This family of Machine Learning algorithms is called Supervised Learning.
当你想到解决分类问题的机器学习方法时，即当你需要确定某个特定数据点的类别或范畴时，你很可能会想到收集一个训练数据集，其中每一个数据点都标注了其对应的类别。这一类机器学习算法被称为监督学习。

However, data is one of the biggest bottlenecks when it comes to training a Machine Learning model, and among the other bottlenecks are compute resources and time necessary to train the model. One can also argue that all of these constraints equate to money. For instance, you need money to acquire or invest in creating more data, to provision hardware for higher compute volumes and, the time you spend training and tuning your model also represents a business opportunity cost.
然而，数据是训练机器学习模型时最大的瓶颈之一，其他瓶颈还包括训练模型所需的计算资源和时间。也可以说，所有这些限制最终都等同于金钱。例如，你需要资金来获取或投入创建更多数据，配置更高计算量的硬件；而你花费在训练和调优模型上的时间，也代表了一种商业机会成本。

On top of this, there are several problem areas where it’s hard to get good quality labeled data. For example it’s hard and expensive to get data for image classification or drug discovery. To address the fact that in real world problems labeled data can be scarce, researchers developed a family of Machine Learning algorithms that, in addition to using labeled data, can also use unlabeled data points to train a classifier. This family of Machine Learning algorithms is called Semi-Supervised Learning.
此外，在某些领域，获取高质量的标记数据非常困难。例如，在图像分类或药物发现领域，获取数据既困难又昂贵。为了解决现实问题中标记数据可能稀缺的情况，研究人员开发了一类机器学习算法，除了使用标记数据外，还可以利用未标记的数据点来训练分类器。这一类机器学习算法被称为半监督学习。

### Supervised vs Semi-Supervised Learning
### 监督学习与半监督学习

You have a set of labeled data points of size $l$ and each data point $(x_i, y_i)$ is an object in space $X$ such that each $x_i$ belongs to the space $X$ and is associated with a label $y_i$. The label $y_i$ is the true label or ground truth for that data point, in the case of a classification problem. After training the model, you can give it a never-seen-before data point $x^*$, and the model would be able to predict its label $y^*$.
你拥有一组大小为 $l$ 的标记数据点，每个数据点 $(x_i, y_i)$ 都是空间 $X$ 中的一个对象，其中每个 $x_i$ 属于空间 $X$ 并关联一个标签 $y_i$。在分类问题中，标签 $y_i$ 是该数据点的真实标签或“地面真值”（ground truth）。模型训练完成后，你可以给它一个从未见过的数据点 $x^*$，模型将能够预测其标签 $y^*$。

This is great but, as mentioned before, in the real world you might not have enough labeled data to train a model with acceptable performance for your use case. So one approach is to leverage unlabeled data and thus develop a Semi-Supervised Machine Learning model, that combines:
这固然很好，但如前所述，在现实世界中，你可能没有足够的标记数据来训练出一个在你的用例中表现良好的模型。因此，一种方法是利用未标记数据，从而开发出一种半监督机器学习模型，它结合了：
*   labeled data points, i.e., for which the true label (ground truth) is known
*   标记数据点，即已知真实标签（地面真值）的数据点
*   unlabelled data points, i.e., without information about its true label (ground truth)
*   未标记数据点，即没有关于其真实标签（地面真值）信息的数据点

At this point you might be thinking: "In any situation where labeled data is scarce or expensive, I can just add unlabeled data and my model will be better?" It would be amazing if you could have your small labeled dataset and then, just by adding a ton more of unlabelled data build a model that is exponentially better than the one you built before, solely with labeled data.
此时你可能会想：“在任何标记数据稀缺或昂贵的情况下，我只需要添加未标记数据，我的模型就会变得更好吗？” 如果你能拥有一个小型的标记数据集，然后仅仅通过添加大量未标记数据，就能构建出一个比仅使用标记数据构建的模型好上数倍的模型，那将是非常棒的。

Unfortunately, it’s not that simple. Adding tons of unlabelled data to the algorithm’s training process is not enough to guarantee it’s going to improve predictions. It’s necessary that the unlabelled data carries information useful for label prediction, that is not yet present in the labeled data and can’t be easily extracted from it.
遗憾的是，事情并没有那么简单。在算法的训练过程中添加大量的未标记数据，并不能保证预测效果一定会提升。关键在于，未标记数据必须携带对标签预测有用的信息，而这些信息在现有的标记数据中尚未体现，且无法轻易从中提取出来。

### Data Assumptions for Semi-Supervised Learning
### 半监督学习的数据假设

In order to be able to use unlabelled data, it’s necessary that the underlying marginal data distribution $p(x)$ over the input space contains information about the posterior distribution $p(y|x)$. Otherwise, it’s been proved that it’s virtually impossible to improve the prediction accuracy just by adding unlabelled data. In sum, the distribution of unlabelled data needs to follow a set of assumptions, in order to effectively improve the classifier.
为了能够使用未标记数据，输入空间上的潜在边缘数据分布 $p(x)$ 必须包含关于后验分布 $p(y|x)$ 的信息。否则，事实证明，仅通过添加未标记数据几乎不可能提高预测准确率。总之，未标记数据的分布需要遵循一系列假设，才能有效地改进分类器。

Different algorithms will follow one or more of these assumptions about the data:
不同的算法会遵循以下关于数据的一个或多个假设：
*   **Smoothness Assumption (平滑假设):** If two samples $x$ and $x'$ are close in the input space, their labels $y$ and $y'$ should be the same.
    如果两个样本 $x$ 和 $x'$ 在输入空间中很接近，它们的标签 $y$ 和 $y'$ 应该相同。
*   **Cluster Assumption (聚类假设):** We can use unlabelled data to find clusters. This assumption is related to the Smoothness Assumption in the sense that it’s said that you can use unlabelled data to find clusters of data and, therefore, propagate labels to data points to unlabelled if they are in the same cluster as labeled data points.
    我们可以利用未标记数据来寻找聚类。这一假设与平滑假设相关，即你可以利用未标记数据发现数据簇，从而将标签传播给与标记数据点处于同一簇中的未标记数据点。
*   **Low-Density Assumption (低密度假设):** The decision boundary shouldn’t pass through high density areas in the input space. The decision boundary is the invisible line or plane that separates the data points in different classes or labels.
    决策边界不应穿过输入空间中的高密度区域。决策边界是将不同类别或标签的数据点分隔开的无形线条或平面。
