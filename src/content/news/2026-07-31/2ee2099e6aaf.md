# A Simplified View of the Jacobian Conjecture
# 雅可比猜想的简化视角

The full conjecture is stated over abstract fields, but the counterexample is a concrete 3D function that we can explain and visualize using familiar geometric ideas and a little algebra.
该猜想的完整表述是基于抽象域的，但其反例是一个具体的 3D 函数，我们可以利用熟悉的几何概念和简单的代数知识来解释和可视化它。

It’s likely that you’ve heard about a new mathematical result announced by Levent Alpöge that came out of work with Fable a few days ago concerning something called the Jacobian conjecture. Unfortunately, many discussions of the result simply repeat parts of the conjecture’s formal definition, with little in the way of a widely accessible explanation.
你可能已经听说，Levent Alpöge 几天前宣布了一项与 Fable 合作得出的新数学成果，涉及所谓的“雅可比猜想”。遗憾的是，许多关于该结果的讨论仅仅重复了猜想的形式化定义，却鲜有通俗易懂的解释。

It’s an understandable problem because mathematicians tend to use very formal language. That language has the advantage of being precise, but the disadvantage of using terms that don’t mean anything to most people. Unfortunately, explaining all of the surrounding terminology from scratch can take about as long as earning a PhD in math.
这是一个可以理解的问题，因为数学家倾向于使用非常正式的语言。这种语言的优点是精确，但缺点是使用了对大多数人来说毫无意义的术语。不幸的是，从头开始解释所有相关术语所需的时间，可能相当于攻读一个数学博士学位。

However, in this case the mathematical result has a relatively simple explanation that can be understood without a PhD. Some precision is inevitably lost by expressing it simply, but the core idea becomes much easier to understand. The explanation still requires some math, but at the level of a typical STEM undergraduate rather than a math PhD.
然而，在这种情况下，该数学成果有一个相对简单的解释，无需博士学位也能理解。虽然简单化表达不可避免地会损失一些精确性，但核心思想变得容易理解多了。这种解释仍然需要一些数学基础，但处于典型的理工科本科生水平，而非数学博士水平。

The Jacobian Conjecture asks whether a particular type of function must always be invertible. The disproof of the conjecture is simply a counterexample: a function that meets all the conjecture’s requirements but provably cannot be inverted.
雅可比猜想探讨的是：某种特定类型的函数是否必然是可逆的。对该猜想的证伪只需一个反例：一个满足猜想所有要求，但被证明无法求逆的函数。

As a reminder, a function can be invertible only if its output uniquely determines its input. If a function produces the same output for two different inputs, then it cannot be reversed. There are also other requirements for a function to be invertible, but a function without this necessary “one-to-one” property cannot be inverted.
提醒一下，函数只有在其输出能唯一确定其输入时才是可逆的。如果一个函数对两个不同的输入产生相同的输出，那么它就无法被逆转。函数可逆还有其他要求，但如果一个函数不具备这种必要的“一一对应”性质，它就无法求逆。

So, if we can find a function that satisfies the Conjecture’s requirements, but the function is nevertheless not one-to-one, then we have a contradiction: The function would match what the conjecture describes, but it can’t be invertible, so the conjecture would be false.
因此，如果我们能找到一个满足猜想要求，但又不是“一一对应”的函数，我们就得到了一个矛盾：该函数符合猜想的描述，但它不可逆，这意味着猜想是错误的。

The formal conjecture applies to polynomial functions over any “field of characteristic zero”. However, the counterexample only relies on ordinary real numbers in a three-dimensional space. That means that we can explain this counterexample using concepts from the ordinary three-dimensional space we all live in and are familiar with.
形式化的猜想适用于任何“特征为零的域”上的多项式函数。然而，这个反例仅依赖于三维空间中的普通实数。这意味着我们可以利用我们所处且熟悉的普通三维空间概念来解释这个反例。

Imagine a big block of infinitely stretchy rubber. Technically, this would be an infinitely large block of rubber that fills the whole universe. Obviously, that’s not possible, but we can still imagine a giant block of rubber that never ends. Now imagine reshaping that rubber by stretching it, bending it, twisting it, and otherwise deforming it.
想象一块具有无限延展性的巨大橡胶块。从技术上讲，这是一块填满整个宇宙的无限大橡胶块。显然，这在现实中是不可能的，但我们仍然可以想象一块永无止境的巨大橡胶块。现在想象通过拉伸、弯曲、扭转或其他方式来重塑这块橡胶。

Every point in the rubber starts at some (x,y,z) location in space, and we deform the block by moving each point to some new (x,y,z) location. This function we’ve been talking about essentially tells us where to move each point. A function that tells us how to reshape an object is a fairly common concept and is often called a deformer or deformation function.
橡胶中的每个点最初都位于空间中的某个 (x,y,z) 位置，我们通过将每个点移动到新的 (x,y,z) 位置来使橡胶块变形。我们一直在讨论的这个函数，本质上就是告诉我们如何移动每个点。一个告诉我们如何重塑物体的函数是一个相当普遍的概念，通常被称为变形器或变形函数。

If we allowed just any function, then it could do nasty things to the rubber. It might tear apart neighboring points, produce sharp creases, or collapse an entire volume down to a degenerate surface, line, or single point. The conjecture does not allow those sorts of things.
如果我们允许使用任何函数，它可能会对橡胶造成破坏。它可能会撕裂相邻的点、产生尖锐的折痕，或者将整个体积坍缩成退化的曲面、线条或单个点。而该猜想不允许出现这些情况。

The conjecture requires that the function have its “Jacobian determinant” to be constant and nonzero. In this context, the Jacobian can be thought of as a set of vectors that describe how our rubber block is locally stretched/compressed in different directions. The determinant of the Jacobian then tells us how much the volume of the rubber is expanded/compressed at a given point.
该猜想要求函数的“雅可比行列式”必须是常数且非零。在这种背景下，雅可比矩阵可以被看作是一组向量，描述了我们的橡胶块在不同方向上是如何局部拉伸或压缩的。雅可比行列式则告诉我们在给定点处橡胶的体积膨胀或压缩了多少。

If the determinant is zero somewhere, then that is a location where, essentially, a volume of the rubber would be compressed down to zero. This requirement that the determinant can’t be zero anywhere, combined with the previous requirement that the function be polynomial, means that the rubber can stretch or compress, but it cannot pinch, crease, tear, or collapse. It must stay smooth everywhere.
如果行列式在某处为零，那么在该位置，橡胶的体积本质上会被压缩为零。行列式在任何地方都不能为零的要求，加上之前关于函数必须是多项式的要求，意味着橡胶可以拉伸或压缩，但不能出现挤压、折痕、撕裂或坍缩。它必须在任何地方都保持平滑。

This rubber block fills all of space because the conjecture concerns a function defined on all of space. This means the function must be smooth and well defined everywhere. Otherwise, we could just cut any problem locations out of the block and pretend they weren’t there.
这个橡胶块填满了整个空间，因为该猜想涉及的是定义在整个空间上的函数。这意味着该函数必须在任何地方都是平滑且定义良好的。否则，我们只需将问题区域从橡胶块中切除，假装它们不存在即可。

Using this perspective, we can now express the simplified version of the Jacobian conjecture in plain language: Can we smoothly deform the infinite block of rubber so that at least two distant parts of it end up occupying the same place, even though nothing is ever locally pinched, creased, torn, or collapsed?
利用这个视角，我们现在可以用通俗的语言表达雅可比猜想的简化版本：我们能否平滑地变形这块无限大的橡胶，使得至少两个遥远的部分最终占据同一个位置，同时在局部没有任何挤压、折痕、撕裂或坍缩？

Keep in mind that even though this is a simplified version of the Jacobian Conjecture, it is still covered by the full formal version. If our simple version is not true, then the full formal version can’t be true either.
请记住，尽管这是雅可比猜想的简化版本，但它仍然被完整的形式化版本所涵盖。如果我们的简化版本不成立，那么完整的形式化版本也不可能成立。

What Alpöge found with Fable is actually rather clean and simple. It is a function that meets the Jacobian Conjecture’s requirements, but it’s still not invertible. Specifically: It is a polynomial function that maps 3D space to 3D space, so we can use it to deform our rubber block, and It’s a polynomial with Jacobian determinant nonzero and constant, so the deformation doesn’t have any pinches, creases, or other problems, but It also produces the same output for multiple inputs, so our deformed block of rubber would end up overlapping itself.
Alpöge 与 Fable 发现的结果实际上非常简洁明了。这是一个满足雅可比猜想要求，但仍然不可逆的函数。具体来说：它是一个将 3D 空间映射到 3D 空间的多项式函数，因此我们可以用它来变形我们的橡胶块；它是一个雅可比行列式为非零常数的多项式，因此变形过程中没有任何挤压、折痕或其他问题；但它同时对多个输入产生相同的输出，因此我们变形后的橡胶块最终会发生重叠。
