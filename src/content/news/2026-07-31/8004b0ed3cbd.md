### Angular was built for codebases where no one person could review every change, and agent-generated code is that same problem arriving faster.

Angular 的构建初衷是为了应对那些规模庞大、单人无法完成全量代码审查的代码库；而 AI 智能体生成的代码，正让这一问题以更快的速度到来。

### So if you're going to let a machine write most of it, write it somewhere that argues back. That's the case for Angular.

因此，如果你打算让机器编写大部分代码，那么请选择一个会“反驳”你的框架。这正是 Angular 存在的意义。
