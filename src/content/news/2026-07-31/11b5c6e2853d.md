# TraceCLIP: Recovering Local Semantics from Patch-to-CLS Contributions
# TraceCLIP：从 Patch-to-CLS 贡献中恢复局部语义

Dense vision-language understanding, including object localization, region recognition, and open-vocabulary semantic segmentation, requires associating language concepts with spatially grounded visual regions.
密集视觉语言理解（包括目标定位、区域识别和开放词汇语义分割）需要将语言概念与空间定位的视觉区域相关联。

CLIP provides a strong foundation for these tasks by learning a shared image-text embedding space from large-scale contrastive pre-training. However, its image-level objective aligns text with a CLS-derived global representation, leaving local vision-language correspondence only indirectly constrained.
CLIP 通过大规模对比预训练学习共享的图像-文本嵌入空间，为这些任务提供了坚实的基础。然而，其图像级目标将文本与 CLS 导出的全局表示对齐，导致局部视觉-语言对应关系仅受到间接约束。

Existing methods either introduce additional supervision, external models, or task-specific adaptation, while training-free approaches mainly recover dense responses from existing patch features without examining where local semantics become most accessible within CLIP.
现有方法要么引入额外的监督、外部模型或特定任务的适配，而无需训练的方法主要从现有的 Patch 特征中恢复密集响应，却未深入探究局部语义在 CLIP 内部何处最易获取。

We introduce TraceCLIP, a training-free framework that recovers latent patch-level semantic evidence by isolating the patch-specific terms written into the CLS attention output.
我们提出了 TraceCLIP，这是一个无需训练的框架，通过分离写入 CLS 注意力输出的特定 Patch 项，来恢复潜在的 Patch 级语义证据。

TraceCLIP further converts contribution-derived semantic responses into a semantic-geodesic topology gate that calibrates final-layer patch affinity for dense feature reconstruction.
TraceCLIP 进一步将基于贡献的语义响应转换为语义测地线拓扑门（semantic-geodesic topology gate），用于校准最终层 Patch 的亲和力，从而实现密集特征重建。

Diagnostic experiments show that these contribution features exhibit strong local semantic discrimination and text-conditioned spatial alignment.
诊断实验表明，这些贡献特征表现出强大的局部语义辨别能力和文本条件下的空间对齐能力。

On eight zero-shot semantic segmentation benchmarks, TraceCLIP achieves gains of 1.3 to 4.5 points in average mIoU over the strongest prior training-free methods across both backbones and background settings, without additional training, external vision foundation models, or region-level supervision.
在八个零样本语义分割基准测试中，TraceCLIP 在各种骨干网络和背景设置下，相比最强的现有无需训练方法，平均 mIoU 提升了 1.3 到 4.5 个百分点，且无需额外训练、外部视觉基础模型或区域级监督。

More broadly, these findings suggest that spatially localized semantics may remain accessible within the internal construction of globally aligned representations.
更广泛地说，这些发现表明，空间局部化的语义可能仍然存在于全局对齐表示的内部结构中，并可被获取。
