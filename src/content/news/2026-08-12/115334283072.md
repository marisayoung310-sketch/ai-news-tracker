# Briar is in maintenance mode
# Briar 进入维护模式

July 9, 2026 Briar is in maintenance mode
2026 年 7 月 9 日，Briar 进入维护模式

This is a quick update about the status of Briar. Short version: the project is still active but we’re only making essential security updates and bugfixes for now.
这是一份关于 Briar 状态的简要更新。简而言之：该项目目前依然活跃，但我们现阶段仅会进行必要的安全更新和错误修复。

Long version: For several years we’ve been trying to find solutions to some of the longstanding issues with Briar, such as high battery usage and unreliable background operation on Android, missing features like account backup and file attachments, and a difficult user experience for adding contacts and communicating offline. We considered completely rebuilding the application from the ground up, or even splitting it into separate applications for online and offline use. Meanwhile, the project didn’t have funding, we were reluctant to look for funding without having a long-term plan, and so we could only work on Briar in our spare time.
详细说明：多年来，我们一直试图解决 Briar 的一些长期存在的问题，例如 Android 平台上电池消耗过高、后台运行不稳定，缺失账户备份和文件附件等功能，以及在添加联系人和离线通信方面糟糕的用户体验。我们曾考虑过从零开始彻底重构应用程序，甚至将其拆分为在线和离线使用的独立应用。与此同时，该项目缺乏资金，在没有长期规划的情况下我们也不愿寻求资助，因此我们只能利用业余时间维护 Briar。

Last year, we decided that we wouldn’t realistically be able to solve these issues and so we reluctantly decided to shut down the project. We worked on releasing a final update for Android and desktop to allow the app to remain functional for as long as possible. In the meantime we were hearing a lot of supportive words from people we had told about our decision, and the app continued to attract new users. So finally we decided to continue the project in maintenance mode.
去年，我们认为在现实中无法解决这些问题，因此不情愿地决定关闭该项目。我们致力于发布 Android 和桌面端的最终更新，以确保该应用能尽可能长时间地保持可用。在此期间，我们从得知这一决定的用户那里听到了许多支持的声音，且该应用仍在持续吸引新用户。因此，最终我们决定以维护模式继续该项目。

We’re only making essential security updates and bugfixes for now, but eventually we hope to make some incremental progress on those longstanding issues.
目前我们仅进行必要的安全更新和错误修复，但我们希望最终能针对那些长期存在的问题取得一些渐进式的进展。

We’re sending out this update because some rumours have been circulating that the project is shutting down, based on conversations we had with people in the internet freedom and privacy community last year. Those rumours are out of date: the project is continuing.
我们发布此更新是因为近期流传着一些关于项目即将关闭的谣言，这些谣言源于我们去年与互联网自由和隐私社区人士的交流。这些谣言已经过时：项目仍在继续。

Briar has received funding from the Small Media Foundation, the Open Internet Tools Project, Access Now, the Open Technology Fund, the Prototype Fund, Internews, the NLnet Foundation, the Next Generation Internet programme, the ISC Project and eQualit.ie.
Briar 曾获得以下机构的资助：Small Media Foundation、Open Internet Tools Project、Access Now、Open Technology Fund、Prototype Fund、Internews、NLnet Foundation、Next Generation Internet programme、ISC Project 以及 eQualit.ie。
