# OpenAI launches ChatGPT desktop app for Linux
# OpenAI 发布 Linux 版 ChatGPT 桌面应用

ChatGPT is on desktops across the world, but there’s been one place where it’s been lacking: the Linux community. Certain sectors of the open source developer community have been clamoring for OpenAI to bring its chatbot to their neck of the woods. As of this week, OpenAI has rectified this oversight, launching a dedicated ChatGPT app for Linux.

ChatGPT 已经遍布全球各地的桌面端，但一直以来有一个领域处于空白状态：Linux 社区。开源开发者社区中的某些群体一直强烈要求 OpenAI 将其聊天机器人引入他们的平台。本周，OpenAI 终于弥补了这一疏忽，正式推出了专为 Linux 开发的 ChatGPT 应用。

“Linux has been one of the most-requested platforms for the desktop app, and this launch extends ChatGPT and Codex across every major desktop operating system,” the company said Tuesday. The new app, which is being released in preview, will give Linux users the ability to use ChatGPT, ChatGPT Work, and Codex on a number of different distributions. The release is worldwide, as of Tuesday.

OpenAI 在周二表示：“Linux 是桌面应用中最受期待的平台之一，此次发布标志着 ChatGPT 和 Codex 已覆盖所有主流桌面操作系统。”这款以预览版形式发布的新应用，将使 Linux 用户能够在多种不同的发行版上使用 ChatGPT、ChatGPT Work 和 Codex。该应用已于周二在全球范围内发布。

OpenAI says that the distros that will be supported include desktop variants of Ubuntu 24.04 and 26.04 LTS, Debian 13, and Fedora 43 and 44. The totality of the Linux community comprises hundreds of distributions, although the distros that OpenAI has chosen here act as the base for a variety of “downstream” desktop distros or “flavors,” which should also be compatible with OpenAI’s apps as a result.

OpenAI 表示，目前支持的发行版包括 Ubuntu 24.04 和 26.04 LTS、Debian 13 以及 Fedora 43 和 44 的桌面版本。虽然 Linux 社区包含数百种发行版，但 OpenAI 选择的这些版本是许多“下游”桌面发行版或“衍生版”的基础，因此这些衍生版本理应也能兼容 OpenAI 的应用。

OpenAI is a little behind Anthropic, which released a Claude desktop app for Linux about a month ago. Anthropic’s app is available for Ubuntu 22.04 or later and Debian 12 or later.

在这一动作上，OpenAI 比 Anthropic 稍晚了一些，后者在大约一个月前就发布了 Linux 版 Claude 桌面应用。Anthropic 的应用支持 Ubuntu 22.04 或更高版本，以及 Debian 12 或更高版本。
