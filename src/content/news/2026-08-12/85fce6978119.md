# SkillConsist: Detecting Inconsistencies in Agent Skills via Bidirectional Graph Alignment
# SkillConsist：通过双向图对齐检测智能体技能中的不一致性

Agent Skills provide reusable capabilities to LLM agents. Agent Skill inconsistencies can expose undisclosed dangerous behavior or cause wrong Skill selection. Recent Agent Skill research has increasingly examined Agent Skill consistency detection. Existing methods evaluate behaviors or security-property graphs against predefined categories or declared scopes. More recently, PL-HCL uses an LLM-based model to learn consistency across metadata, instructions, and resources.

智能体技能（Agent Skills）为大语言模型（LLM）智能体提供了可重用的能力。智能体技能的不一致性可能会暴露未公开的危险行为，或导致错误的技能选择。近期，关于智能体技能的研究越来越多地关注技能一致性检测。现有方法通常根据预定义的类别或声明的范围来评估行为或安全属性图。最近，PL-HCL 使用基于 LLM 的模型来学习元数据、指令和资源之间的一致性。

However, declaration and implementation behavior can be mixed across text and code, and a concise declaration can correspond to multiple connected implementation steps. We present SkillConsist to address both challenges. An LLM separates declaration and implementation content into behavior records on the implementation and declaration sides, while static analysis supplements implementation records. These records form declaration and implementation behavior graphs, respectively.

然而，声明与实现行为可能混合在文本和代码中，且简洁的声明可能对应多个相互关联的实现步骤。我们提出了 SkillConsist 来应对这两个挑战。LLM 将声明和实现内容分离为实现侧和声明侧的行为记录，同时通过静态分析补充实现记录。这些记录分别构成了声明行为图和实现行为图。

Starting from a behavior record on either side, bidirectional graph alignment searches the other graph for a candidate subgraph and expands it along behavior relations until it completely expresses the source-side behavior. Graph differencing identifies conflicts between aligned subgraphs and outputs the detection results.

从任一侧的行为记录出发，双向图对齐（Bidirectional graph alignment）会在另一张图中搜索候选子图，并沿着行为关系进行扩展，直到完全表达源侧的行为。图差异分析（Graph differencing）用于识别对齐子图之间的冲突，并输出检测结果。

We construct a 633-Skill benchmark from ClawHub's 500 most-downloaded public Skills and 133 Skill-Inject packages. The benchmark contains 319 inconsistent and 314 consistent Skills and 442 localized inconsistency annotations. On this benchmark, SkillConsist achieves 86.85% precision, 89.03% recall, and 87.93% F1 for package-level detection, improving F1 over the best baseline by 20.43 percentage points. For localization, it achieves 67.60% precision, 58.14% recall, and 62.52% F1.

我们构建了一个包含 633 个技能的基准测试集，该数据集来自 ClawHub 上下载量最高的 500 个公共技能和 133 个 Skill-Inject 包。该基准测试包含 319 个不一致技能、314 个一致技能以及 442 个局部不一致性标注。在此基准测试中，SkillConsist 在包级检测中达到了 86.85% 的精确率、89.03% 的召回率和 87.93% 的 F1 分数，较最佳基准模型提升了 20.43 个百分点。在定位任务中，它达到了 67.60% 的精确率、58.14% 的召回率和 62.52% 的 F1 分数。
