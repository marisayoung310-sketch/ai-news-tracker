# Bitchat is now on Radicle
# Bitchat 现已入驻 Radicle

Bitchat has officially migrated its development and collaboration workflow to Radicle, a decentralized code collaboration platform. This move aligns with the project's commitment to censorship resistance and peer-to-peer infrastructure.

Bitchat 已正式将其开发与协作工作流迁移至去中心化代码协作平台 Radicle。此举符合该项目对抗审查和构建点对点基础设施的承诺。

By leveraging Radicle, Bitchat developers can now manage their repositories and collaborate on code without relying on centralized intermediaries. This transition ensures that the project remains accessible and verifiable by the community, regardless of external pressures or platform policies.

通过利用 Radicle，Bitchat 的开发者现在可以在不依赖中心化中介的情况下管理代码仓库并进行协作。这一转变确保了该项目能够持续保持可访问性和社区可验证性，不受外部压力或平台政策的影响。

Users and contributors can now find the Bitchat source code and project updates on the Radicle network, marking a significant step forward in the project's decentralization roadmap.

用户和贡献者现在可以在 Radicle 网络上找到 Bitchat 的源代码和项目更新，这标志着该项目在去中心化路线图上迈出了重要的一步。
