# Toward High-Fidelity 3D Point-Cloud Learning for Brain Folding Morphology Prediction Using Trans-Unet
# 基于 Trans-Unet 的高保真 3D 点云学习：用于大脑折叠形态预测

**Abstract:** Learning high-fidelity point-cloud features in the 3D space poses significant challenges, including permutation invariance, lack of local context, difficulty in fine-grained surface reconstruction, and high computational cost. 

**摘要：** 在 3D 空间中学习高保真点云特征面临着诸多重大挑战，包括置换不变性、缺乏局部上下文、细粒度表面重建困难以及高昂的计算成本。

In this article, we propose Trans-Unet, a novel framework that addresses these issues by first transforming 3D point-cloud data into a 2D grid domain and then employing a U-shaped hybrid model that integrates Convolutional Neural Networks and self-attention mechanisms. 

在本文中，我们提出了 Trans-Unet，这是一个旨在解决上述问题的新型框架。该框架首先将 3D 点云数据转换为 2D 网格域，随后采用一种结合了卷积神经网络（CNN）与自注意力机制的 U 型混合模型。

The proposed Trans-Unet effectively learns and reconstructs precise features from high-resolution 3D point-cloud data (with 40,401 points in surface and 2,382 points in fiber) derived from a predefined finite element brain patch growth model, enabling accurate prediction of brain folding patterns. 

所提出的 Trans-Unet 能够从预定义的有限元大脑皮层生长模型导出的高分辨率 3D 点云数据（包含 40,401 个表面点和 2,382 个纤维点）中，有效地学习并重建精确特征，从而实现对大脑折叠模式的准确预测。

By combining multiple techniques, Trans-Unet leverages the complementary strengths: the 3D-to-2D transformation preserves fine-grained structural information while significantly reducing computational cost and the curse of dimensionality; convolutional blocks capture hierarchical, low-level local representations; and the self-attention mechanism models global, high-level semantics and long-range dependencies. 

通过结合多种技术，Trans-Unet 发挥了互补优势：3D 到 2D 的转换在保留细粒度结构信息的同时，显著降低了计算成本和维度灾难；卷积模块能够捕捉分层级的低级局部表征；而自注意力机制则用于建模全局、高级语义及长距离依赖关系。

The dataset consists of 3D point-clouds containing both brain surface patches and fiber information generated by a large-scale finite element model. Trans-Unet is applied to predict brain surface folding from the initial state (state 0 or states 0-2) to the final state (state 3). 

该数据集由大规模有限元模型生成，包含大脑表面皮层和纤维信息的 3D 点云。Trans-Unet 被应用于预测大脑表面从初始状态（状态 0 或状态 0-2）到最终状态（状态 3）的折叠过程。

Experimental results demonstrate that Trans-Unet achieves high-resolution predictions of brain patch growth, surpassing existing methods in both fidelity and accuracy.

实验结果表明，Trans-Unet 实现了大脑皮层生长的高分辨率预测，在保真度和准确性方面均优于现有方法。
