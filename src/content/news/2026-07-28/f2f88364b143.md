### Toward User-Conditioned Evaluation of Personal LLM Agents under Temporal Interventions
### 面向时间干预下个人大模型智能体的用户条件评估

**Abstract:** Personal agents maintain memories, learned skills, tool configurations, and policy state that evolve with each user. Existing agent benchmarks often evaluate these capabilities in isolation: tool benchmarks test invocation under fixed APIs, memory benchmarks test recall or forgetting, and safety benchmarks test static policy compliance.

**摘要：** 个人智能体维护着随每位用户而演变的记忆、习得技能、工具配置及策略状态。现有的智能体基准测试通常孤立地评估这些能力：工具基准测试在固定 API 下测试调用能力，记忆基准测试测试回忆或遗忘能力，而安全基准测试则测试静态策略的合规性。

We argue that personal-agent evaluation requires a different protocol: replaying the same temporal intervention across different persistent user-conditioned states and measuring how failures propagate across agent components. We formalize this requirement as four conditions: explicit temporal intervention, persistent state across the intervention, induced cross-dimensional effects, and variation in user-conditioned state.

我们认为，个人智能体的评估需要一套不同的协议：在不同的持久化用户条件状态下重现相同的时间干预，并衡量故障如何在智能体组件之间传播。我们将这一要求形式化为四个条件：明确的时间干预、跨干预的持久状态、诱导的跨维度效应，以及用户条件状态的变化。

A focused audit of public benchmark protocols selected by explicit inclusion criteria identifies several close cases. Under our explicitly narrow operationalization, we did not find a protocol in that audited set satisfying all four conditions. This claim is scoped as a focused gap analysis with bounded literature coverage.

通过明确的纳入标准对公共基准测试协议进行的重点审计，我们识别出了一些接近的案例。在我们明确且严格的操作化定义下，审计集中的所有协议均未能同时满足这四个条件。此结论仅作为一项具有文献覆盖范围限制的重点差距分析。

This position paper proposes a minimal benchmark design and candidate reporting metrics for user-conditioned adaptation. The result is a concrete design requirement for future personal-agent evaluation, with metrics used as reporting tools for that requirement.

本立场论文提出了一种针对用户条件适应性的最小化基准设计及候选报告指标。其成果为未来个人智能体评估提供了一项具体的架构要求，并将相关指标作为实现该要求的报告工具。
