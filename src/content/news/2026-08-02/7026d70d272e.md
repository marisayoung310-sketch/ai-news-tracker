# iv-org / invidious

Invidious is an open-source alternative front-end to YouTube.
Invidious 是 YouTube 的开源替代前端。

### Features
### 功能特性

**User features**
**用户功能**
* Lightweight
* 轻量级
* No ads
* 无广告
* No tracking
* 无追踪
* No JavaScript required
* 无需 JavaScript
* Light/Dark themes
* 明亮/深色主题
* Customizable homepage
* 可自定义主页
* Subscriptions independent from Google
* 订阅与 Google 账号解耦
* Notifications for all subscribed channels
* 所有订阅频道的通知
* Audio-only mode (with background play on mobile)
* 纯音频模式（支持移动端后台播放）
* Support for Reddit comments
* 支持 Reddit 评论
* Available in many languages, thanks to our translators
* 得益于译者们的贡献，支持多种语言

**Data import/export**
**数据导入/导出**
* Import subscriptions from YouTube, NewPipe and FreeTube
* 从 YouTube、NewPipe 和 FreeTube 导入订阅
* Import watch history from YouTube and NewPipe
* 从 YouTube 和 NewPipe 导入观看历史
* Export subscriptions to NewPipe and FreeTube
* 导出订阅到 NewPipe 和 FreeTube
* Import/Export Invidious user data
* 导入/导出 Invidious 用户数据

**Technical features**
**技术特性**
* Embedded video support
* 支持嵌入式视频
* Developer API
* 开发者 API
* Does not use official YouTube APIs
* 不使用官方 YouTube API
* No Contributor License Agreement (CLA)
* 无需贡献者许可协议 (CLA)

### 快速开始

**Using Invidious:** Select a public instance from the list and start watching videos right now!
**使用 Invidious：** 从列表中选择一个公共实例，即可立即开始观看视频！

**Hosting Invidious:** Follow the installation instructions.
**托管 Invidious：** 请遵循安装指南。

### Extensions
### 扩展程序

We highly recommend the use of Privacy Redirect, a browser extension that automatically redirects YouTube URLs to any Invidious instance and replaces embedded YouTube videos on other websites with Invidious. The documentation contains a list of browser extensions that we recommended to use along with Invidious. You can read more here: https://docs.invidious.io/applications/
我们强烈建议使用 Privacy Redirect，这是一款浏览器扩展，可自动将 YouTube URL 重定向到任意 Invidious 实例，并将其他网站上的嵌入式 YouTube 视频替换为 Invidious。文档中包含了一份我们推荐与 Invidious 配合使用的浏览器扩展列表。您可以在此处阅读更多信息：https://docs.invidious.io/applications/

### Contribute
### 贡献

**Code:** Fork it ( https://github.com/iv-org/invidious/fork ). Create your feature branch (git checkout -b my-new-feature). Stage your files (git add .). Commit your changes (git commit -m 'Add some feature'). Push to the branch (git push origin my-new-feature). Create a new pull request ( https://github.com/iv-org/invidious/compare ).
**代码：** Fork 本项目 ( https://github.com/iv-org/invidious/fork )。创建您的功能分支 (git checkout -b my-new-feature)。暂存文件 (git add .)。提交更改 (git commit -m 'Add some feature')。推送到分支 (git push origin my-new-feature)。创建新的 Pull Request ( https://github.com/iv-org/invidious/compare )。

**Translations:** We use Weblate to manage Invidious translations. You can suggest new translations and/or correction here: https://hosted.weblate.org/engage/invidious/. Creating an account is not required, but recommended, especially if you want to contribute regularly. Weblate also allows you to log-in with major SSO providers like GitHub, GitLab, BitBucket, Google, ...
**翻译：** 我们使用 Weblate 来管理 Invidious 的翻译。您可以在此处建议新的翻译或更正：https://hosted.weblate.org/engage/invidious/。无需创建账户，但建议创建，特别是如果您想定期贡献的话。Weblate 还允许您使用 GitHub、GitLab、BitBucket、Google 等主流 SSO 提供商登录。
