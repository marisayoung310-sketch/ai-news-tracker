# NeuroAdaptTrainer: A Fiji/ImageJ Plugin for YOLO-Based Neuron Segmentation, Interactive Correction and Transfer Learning
# NeuroAdaptTrainer：用于基于 YOLO 的神经元分割、交互式校正和迁移学习的 Fiji/ImageJ 插件

**Abstract:** Neuron counting and segmentation in microscopy images of neuronal cultures is a routine and time-consuming task in neuroscience research, traditionally performed through manual inspection or semi-automatic tools.
**摘要：** 在神经科学研究中，对神经元培养物的显微图像进行神经元计数和分割是一项常规且耗时的任务，传统上通过人工检查或半自动工具来完成。

We present NeuroAdaptTrainer, an open-source Fiji/ImageJ plugin that integrates a YOLO instance-segmentation model directly into the microscopist's workflow.
我们推出了 NeuroAdaptTrainer，这是一个开源的 Fiji/ImageJ 插件，它将 YOLO 实例分割模型直接集成到了显微镜操作员的工作流程中。

The plugin allows a user to run automatic neuron detection on a single image or a batch of images, manually correct the resulting detections from within Fiji, and use those corrections to adapt the model to new imaging conditions via transfer learning.
该插件允许用户对单张或批量图像运行自动神经元检测，在 Fiji 内部手动校正检测结果，并利用这些校正结果通过迁移学习使模型适应新的成像条件。

A built-in external validation module allows the base and adapted models to be compared quantitatively on a held-out annotated set.
内置的外部验证模块允许在预留的标注数据集上对基础模型和适配后的模型进行定量比较。

NeuroAdaptTrainer lowers the barrier for non-specialist users to benefit from deep-learning-based segmentation while keeping expert supervision at the center of the workflow.
NeuroAdaptTrainer 降低了非专业用户从基于深度学习的分割技术中获益的门槛，同时确保专家监督始终处于工作流程的核心地位。
