# Microsoft Edge is about to lock out older ad blockers, just like Chrome did
# 微软 Edge 浏览器即将像 Chrome 一样，封锁旧版广告拦截插件

Microsoft Edge is ending support for the Manifest V2 extensions platform, which will cut off the uBlock Origin adblocker and others like it, just like Google Chrome did earlier this year. According to Microsoft, there are only 58 extensions on the Edge Add-On Store “with any meaningful usage” that still use MV2, and only three of those aren’t available on the newer MV3 platform.

微软 Edge 浏览器即将停止对 Manifest V2 (MV2) 扩展平台的支持。正如谷歌 Chrome 浏览器今年早些时候所做的那样，此举将导致 uBlock Origin 等广告拦截插件无法继续使用。据微软称，在 Edge 插件商店中，仅有 58 款“具有实际使用意义”的扩展程序仍在使用 MV2，其中只有三款尚未适配更新的 MV3 平台。

Anyone still using these extensions can switch to a different adblocker, like uBlock Origin Lite. Or they could use a different browser, like Opera, which still supports existing MV2 extensions and says it will continue to do so “for as long as it’s technically reasonable,” or switch to another browser like Firefox.

目前仍在使用这些扩展程序的用户可以切换到其他广告拦截器，例如 uBlock Origin Lite。或者，用户也可以选择其他浏览器，比如 Opera（该浏览器目前仍支持现有的 MV2 扩展，并表示将“在技术合理的情况下”继续提供支持），或者切换到 Firefox 等其他浏览器。

Starting this month, Microsoft says any remaining MV2 extensions “will be gradually turned off by default,” but users will be notified beforehand. Microsoft plans to finish transitioning all of its consumer users to MV3 extensions by the end of this year before shutting them down for enterprise users in early 2027.

微软表示，从本月开始，任何剩余的 MV2 扩展程序“都将被默认逐步停用”，但用户会提前收到通知。微软计划在今年年底前完成所有个人用户向 MV3 扩展的过渡，并于 2027 年初停止企业用户的 MV2 支持。

Microsoft: Over the next few months, MV2 extensions will be gradually turned off by default. Users will be notified in advance and directed to recommended MV3 versions where available. These changes will start in the Canary, Dev, and Beta channels and gradually broaden to Stable in the following months, with the goal of completing the consumer transition by the end of 2026. Managed devices will not be affected during the consumer rollout. Enterprise deprecation will follow in early 2027.

微软官方表示：在接下来的几个月里，MV2 扩展程序将被默认逐步停用。用户会提前收到通知，并被引导至可用的推荐 MV3 版本。这些更改将首先在 Canary、Dev 和 Beta 频道中实施，并在随后的几个月内逐步扩展到稳定版（Stable），目标是在 2026 年底前完成个人用户的过渡。在个人用户推广期间，受管理的设备（企业设备）将不受影响。针对企业用户的弃用计划将于 2027 年初进行。
