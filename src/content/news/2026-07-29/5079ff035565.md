# EditCLEVR: A Paired-Scene Intervention Benchmark for Compositional Faithfulness of Object-Centric Representations
# EditCLEVR：用于评估以对象为中心的表征组合忠实度的配对场景干预基准

Object-centric learning aims to represent scenes as objects whose properties can be reused in new combinations. Existing evaluations usually score segmentation, single-image factor prediction, or downstream accuracy, but these tests do not directly ask whether a per-object representation behaves correctly under a controlled semantic edit.
以对象为中心的学习旨在将场景表征为对象，并使其属性能够在新的组合中被复用。现有的评估方法通常针对分割、单图像因子预测或下游任务准确率进行评分，但这些测试并未直接考察在受控的语义编辑下，单个对象的表征是否表现正确。

We introduce EditCLEVR, a paired-scene intervention benchmark in which each example contains a before/after pair of CLEVR-style renders with the same object indices and scene layout, and either exactly one known attribute change on one known object or a no-edit re-render for drift measurement.
我们引入了 EditCLEVR，这是一个配对场景干预基准。在该基准中，每个样本都包含一对 CLEVR 风格的渲染图（编辑前后），它们具有相同的对象索引和场景布局；样本要么包含对特定对象进行的单一已知属性更改，要么包含用于测量漂移的无编辑重渲染图。

The protocol includes probe-free diagnostics for representation-change localization and stability, together with probe-decoded semantic faithfulness metrics that test whether the predicted scene change matches the intended intervention across in-distribution and compositional out-of-distribution (OOD) suites, allowing code-space movement and decoded object-attribute correctness to be evaluated separately.
该协议包含用于表征变化定位和稳定性的无探针诊断方法，以及基于探针解码的语义忠实度指标。这些指标用于测试预测的场景变化是否与预期的干预相匹配，并涵盖了分布内（in-distribution）和组合式分布外（OOD）测试集，从而能够分别评估编码空间的变化和解码后对象属性的正确性。

We introduce the semantic metric Scene-Graph Intervention Accuracy (SGIA), which requires the full after-scene prediction to be correct and the only predicted before-to-after semantic change to be the intended object-factor edit. We also establish Delta-SGIA as a companion diagnostic that checks the single-site change pattern without requiring the full after-scene graph to be correct.
我们引入了语义指标“场景图干预准确率”（Scene-Graph Intervention Accuracy, SGIA），该指标要求完整的场景后预测必须正确，且预测的编辑前后语义变化必须仅限于预期的对象因子编辑。我们还建立了 Delta-SGIA 作为配套诊断指标，用于检查单点变化模式，而无需完整场景图预测的正确性。

Baseline evaluations on ground-truth-mask backbones, learned-slot models, SAM 2 + frozen-ViT models, and one mask-feature hybrid indicate that CoGenT-OOD-core degradation can persist under ground-truth instance masks, that mask source accounts for part but not all of native performance, and that locality or stability alone can overstate semantic faithfulness.
通过对真值掩码（ground-truth-mask）骨干网络、学习槽（learned-slot）模型、SAM 2 + 冻结 ViT 模型以及一种掩码-特征混合模型进行的基线评估表明：即使在真值实例掩码下，CoGenT-OOD 核心性能的退化依然存在；掩码来源仅能解释部分而非全部的原始性能差异；且仅凭局部性或稳定性指标可能会高估语义忠实度。
