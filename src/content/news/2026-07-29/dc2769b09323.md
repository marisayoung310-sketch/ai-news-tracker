# Donate to GrapheneOS / 向 GrapheneOS 捐款

GrapheneOS is an open source project supported via donations from individuals, companies and other organizations. Donations are used for paying developers, purchasing hardware (workstations, test devices, debugging cables/boards, etc.), paying for infrastructure (domains, virtual/dedicated servers) and paying legal fees. Donations may also be used for other reasonable, project-related expenses necessary to support and maintain GrapheneOS.
GrapheneOS 是一个开源项目，依靠个人、公司和其他组织的捐款来维持运营。捐款用于支付开发人员薪酬、购买硬件（工作站、测试设备、调试线缆/板等）、支付基础设施费用（域名、虚拟/专用服务器）以及支付法律费用。捐款也可能用于支持和维护 GrapheneOS 所必需的其他合理的项目相关开支。

The multiple ways to donate are listed in the sections on this page. If you are interested in sponsorships, check out our sponsors page.
本页面列出了多种捐款方式。如果您有兴趣进行赞助，请查看我们的赞助商页面。

### GitHub Sponsors (credit card) / GitHub 赞助（信用卡）
GrapheneOS can be sponsored with recurring or one-time donations via credit cards through GitHub Sponsors. There are standard tiers from $5 to $5,000 or you can donate a custom amount.
您可以通过 GitHub Sponsors 使用信用卡对 GrapheneOS 进行定期或一次性捐款。我们设有从 5 美元到 5,000 美元的标准档位，您也可以捐赠自定义金额。

### Wise
If you have a Wise account, you can donate directly via Wise using our Wise Quick Pay link rather than using the bank account details. This enables sending donations from anywhere Wise is available. If the currency you're using isn't listed due to not being one of the currencies where we accept local bank transfers, please select CAD or USD so we can avoid another conversion.
如果您拥有 Wise 账户，可以直接通过我们的 Wise 快速支付链接进行捐款，而无需使用银行账户详情。这使得您可以在任何支持 Wise 的地区进行捐款。如果您使用的货币不在我们接受本地银行转账的币种列表中，请选择 CAD（加元）或 USD（美元），以避免额外的货币转换。

### PayPal
PayPal can be used to make one-time, monthly or yearly donations to the non-profit GrapheneOS Foundation.
您可以使用 PayPal 向非营利组织 GrapheneOS Foundation 进行一次性、每月或每年的捐款。

If possible, use the donation link for your currency. If it's not listed, please use the CAD donation link.
如果可能，请使用您所在货币对应的捐款链接。如果未列出，请使用 CAD（加元）捐款链接。

If you can't use the donation links due to region restrictions, you can send a donation via our PayPal.Me link or via our `paypal@grapheneos.org` email.
如果您因地区限制无法使用捐款链接，可以通过我们的 PayPal.Me 链接或发送至 `paypal@grapheneos.org` 邮箱进行捐款。

PayPal charges a base fee of 30 cents and 2.9% of the donation amount within Canada. There's an additional 0.8% fee for donations from the US and 1% for other countries. Currency conversion adds an additional 4% fee as opposed to the usual PayPal conversion fee of 3%.
PayPal 在加拿大境内收取 30 美分的基础费用及捐款金额 2.9% 的手续费。来自美国的捐款需额外支付 0.8% 的费用，其他国家则为 1%。货币转换会产生额外的 4% 费用，而非通常 PayPal 转换费的 3%。

### Interac e-Transfer
If you have a Canadian bank account, you can send Canadian dollar donations to the non-profit GrapheneOS Foundation via Interac e-Transfer to `donate@grapheneos.org`. The email address has Interac e-Transfer Autodeposit support enabled so no security question is needed.
如果您拥有加拿大银行账户，可以通过 Interac e-Transfer 将加元捐款发送至 `donate@grapheneos.org`。该邮箱已启用 Interac e-Transfer 自动存款功能，因此无需设置安全问题。
