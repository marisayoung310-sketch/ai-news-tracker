# Starting Terraria modding (again)
# 重新开始《泰拉瑞亚》模组开发

This is my first dev blog I'm making a terraria mod I'm not sure if i want to start right now but i am sure to start soon i already have some ideas so here are the ideas.
这是我的第一篇开发日志。我正在制作一个《泰拉瑞亚》模组，虽然我不确定是否现在就开始，但我肯定很快就会动工。我已经有一些想法了，以下是我的构思：

The Operator: The operator is someone i have in idea for a while kind of the lore aspect is you work it, killing bosses and giving proof to the operator for certain rewards, at first it is an Npc but after moon lord you fight him. I might bring him back as the same dude but is occupied by the Fixer as a vessel which he is chained or has custom hand cuffs for the fixer to occupies the fixer without The Operator body, without the body dying.
“操作员”（The Operator）：这个角色我构思已久。从背景设定来看，你为他工作，通过击杀 Boss 并向他提交证明来换取奖励。起初他是一个 NPC，但在击败月球领主后，你需要与他战斗。我可能会让他以同样的身份回归，但此时他的身体被“修复者”（The Fixer）当作容器占据，他被锁链或特制手铐束缚，让“修复者”在不导致“操作员”本体死亡的情况下占据其身体。

The Dulled One: This is not my idea but a alternative version of it (Game: Craft-Wars Redux Roblox, Boss: Dulled Spectrum) for credits, so I really liked this boss idea but I'm really not sure if they did what I'm doing, but his power is to erase or turn into dust or "dull". To erase certain parts of the world either matter, or space i don't want to say time because i feel like that would be boring, it can either be like passive very weak erase which it can re-gain power.
“迟钝者”（The Dulled One）：这个想法并非原创，而是基于（Roblox 游戏《Craft-Wars Redux》中的 Boss“Dulled Spectrum”）的变体，在此注明出处。我非常喜欢这个 Boss 的创意，虽然我不确定他们是否也做了我打算做的这些，但他的能力是抹除、化为尘埃或使其“迟钝”。他可以抹除世界的一部分，无论是物质还是空间——我不想说是时间，因为我觉得那样太无聊了。这种能力可以是被动且微弱的抹除，并能借此恢复力量。

Second version is the Compacted version which does way more damage, maybe one shot if i do one shot then im adding middle attacks, but deplete the dust bar by a ton so if the boss is not careful or the player stops it then you can easily beat it. it might have a regen system where if the bar is full then it heals. Also hammer both the versions the game and mine has hammer. The lore is not very fleshed out right now but i will figure it out.
第二个版本是“压缩版”（Compacted version），它能造成更高的伤害，甚至可能一击必杀。如果我真的加入一击必杀机制，我会增加一些中等强度的攻击，但这种攻击会大量消耗“尘埃条”，所以如果 Boss 不小心或者玩家打断了它，你就能轻松获胜。它可能还会有一个回复系统，当能量条满时会进行自我治疗。此外，两个版本都有锤子，原游戏和我的模组里都有锤子。目前的背景设定还不够完善，但我会慢慢构思出来的。
