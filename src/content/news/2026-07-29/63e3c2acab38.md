# MegaSlide-DiT: Memory-Centric Adaptation and Deformable Local Attention for Efficient Video Diffusion
# MegaSlide-DiT：面向高效视频扩散的内存中心化适配与可变形局部注意力机制

**Abstract:** High-resolution video diffusion models built on Diffusion Transformers (DiTs) deliver strong fidelity but quickly exhaust the memory budget of a single workstation. A 100 billion-plus parameter DiT easily requires over a terabyte of persistent state, while naive spatiotemporal self-attention grows quadratically in sequence length. These two walls -- parameter memory and activation memory -- prevent researchers from adapting massive generative models without large GPU clusters.

**摘要：** 基于扩散变换器（DiTs）构建的高分辨率视频扩散模型虽然具有极高的保真度，但往往会迅速耗尽单台工作站的内存预算。一个拥有千亿级参数的 DiT 模型通常需要超过 1TB 的持久化状态存储，而原始的时空自注意力机制在序列长度上呈二次方增长。参数内存和激活内存这两大障碍，使得研究人员在没有大型 GPU 集群的情况下，难以对大规模生成模型进行适配。

We revisit this problem from a systems perspective and introduce MegaSlide-DiT, a prototype that demonstrates how a pre-trained 105B DiT can be adapted on a single H200 GPU with 1.5 TB of host RAM. Our key insight is that the GPU need not own the model state: all persistent weights, master weights and optimizer moments remain in host memory, while only transient shards are streamed to the GPU on demand.

我们从系统角度重新审视了这一问题，并推出了 MegaSlide-DiT。该原型展示了如何利用单张 H200 GPU 和 1.5TB 的主机内存，对预训练的 105B 参数 DiT 模型进行适配。我们的核心洞察在于：GPU 无需持有完整的模型状态——所有持久化权重、主权重和优化器动量均保留在主机内存中，仅在需要时将瞬态分片（transient shards）流式传输至 GPU。

Simultaneously, we replace quadratic global attention with 3D Deformable Slide Attention (3D-DSA), a motion-adaptive local attention operator that reduces both memory and computational complexity to linear in the sequence length. We report detailed memory accounting, execution traces and evaluation results to substantiate our design.

同时，我们用 3D 可变形滑动注意力（3D-DSA）取代了二次方全局注意力。这是一种运动自适应的局部注意力算子，将内存和计算复杂度均降低至序列长度的线性级别。我们提供了详细的内存核算、执行轨迹和评估结果，以验证我们的设计。

MegaSlide-DiT does not claim to train a 105B model from scratch on a single GPU, nor does it magically solve bandwidth limits; rather, it offers a pragmatic path for full-parameter adaptation of massive video diffusion models on high-end workstations.

MegaSlide-DiT 并不声称能在单张 GPU 上从零开始训练 105B 模型，也不可能凭空解决带宽限制问题；相反，它为在高端工作站上对大规模视频扩散模型进行全参数适配提供了一条切实可行的路径。
