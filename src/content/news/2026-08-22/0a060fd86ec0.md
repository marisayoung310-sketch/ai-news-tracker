# Motorola's GrapheneOS phones will launch in 2027 priced higher than Pixels
# 摩托罗拉 GrapheneOS 手机将于 2027 年发布，价格高于 Pixel

Several months ago, Motorola and the makers of GrapheneOS announced a team-up that would expand support for the privacy-centric OS to beyond Google’s Pixel phones. The announcement, however, was bereft of details. Now, the creators of the OS have taken to Mastodon (naturally) to provide an update. Moto’s GrapheneOS phones are on track to launch in 2027, but they’ll cost a pretty penny.

几个月前，摩托罗拉与 GrapheneOS 的开发者宣布达成合作，将这款以隐私为中心的操作系统支持范围扩展到谷歌 Pixel 手机之外。然而，当时的公告缺乏细节。现在，该操作系统的开发者（不出所料地）在 Mastodon 上发布了最新进展。摩托罗拉的 GrapheneOS 手机计划于 2027 年推出，但价格将相当昂贵。

The upcoming Moto devices won’t ship with GrapheneOS, but they will be fully supported by the project with help from Moto itself. So far, only Pixel phones have met GrapheneOS’s strict hardware requirements to ensure the highest level of security and privacy. The software, which is based on Android, includes features like enhanced memory protection, granular network permissions, customizable app sandboxing, and a duress code that can be used to wipe your phone. (That last one got an activist charged with a felony earlier this year after he used it to delete his data during a customs interrogation.)

即将推出的摩托罗拉设备不会预装 GrapheneOS，但该项目将在摩托罗拉的协助下提供全面支持。到目前为止，只有 Pixel 手机满足了 GrapheneOS 严格的硬件要求，以确保最高水平的安全性和隐私性。该软件基于 Android 开发，包含增强内存保护、细粒度网络权限、可定制的应用沙盒以及可用于清除手机数据的紧急代码等功能。（今年早些时候，一名活动人士在海关审讯中使用该功能删除数据后，被指控犯有重罪。）

According to the GrapheneOS team, the upcoming Moto phones will be premium flagship devices. The team expects pricing to be even higher than Pixel phones, which is saying something. The current Pixel lineup starts at $900 for the base model Pixel 11, a $100 increase from last year. The Pixel 11 Pro XL price has gone up to a whopping $1,300 this year. So these mysterious Moto phones will presumably be well over a grand.

据 GrapheneOS 团队称，即将推出的摩托罗拉手机将是高端旗舰设备。该团队预计其价格甚至会高于 Pixel 手机，这可不是小数目。目前的 Pixel 系列起售价为 900 美元（Pixel 11 基础款），比去年上涨了 100 美元。Pixel 11 Pro XL 今年的价格更是高达 1,300 美元。因此，这些神秘的摩托罗拉手机价格预计将远超 1,000 美元。

Motorola didn’t bother releasing new versions of its non-folding Edge phones in 2026, and if that trend continues, the 2027 devices may be foldables. That would help explain the high prices, and the ongoing AI-driven component price increases can’t be helping either. While Motorola makes plenty of budget devices in the Moto G line, those devices aren’t a viable option. GrapheneOS has supported Pixels because Google’s Tensor chips provide the necessary security features, but not all Qualcomm chips offer the same capabilities.

摩托罗拉在 2026 年没有发布新款非折叠式 Edge 手机，如果这一趋势持续下去，2027 年的设备可能就是折叠屏手机。这有助于解释其高昂的价格，而持续的 AI 驱动的组件价格上涨也难辞其咎。虽然摩托罗拉在 Moto G 系列中生产了大量廉价设备，但这些设备并非可行的选择。GrapheneOS 之所以支持 Pixel，是因为谷歌的 Tensor 芯片提供了必要的安全功能，但并非所有高通芯片都具备同样的能力。

Only Qualcomm’s most expensive 8-series processors are comparable from a security standpoint, and those only go in expensive flagship smartphones. Most of Moto’s recent flagships have been foldables, so that may be the next stop for GrapheneOS. It’s possible that cheaper Moto phones could eventually get GrapheneOS support, but the developers don’t see that happening any time soon. Qualcomm’s mid-range chips don’t get the same level of support unless OEMs pay more, so Motorola would have to commit to that on a wider range of products.

从安全角度来看，只有高通最昂贵的 8 系列处理器才能与之媲美，而这些处理器仅用于昂贵的旗舰智能手机。摩托罗拉最近的大多数旗舰产品都是折叠屏手机，因此这可能是 GrapheneOS 的下一个目标。虽然更便宜的摩托罗拉手机最终可能会获得 GrapheneOS 支持，但开发者认为短期内不会实现。除非原始设备制造商（OEM）支付更多费用，否则高通的中端芯片无法获得同等级别的支持，因此摩托罗拉必须在更广泛的产品线上做出承诺。

As it stands, Motorola only offers update support for a couple of years on budget phones, which isn’t sufficient for GrapheneOS. Motorola hasn’t confirmed a release timeline for these devices, but GrapheneOS should be available for them at launch. The installation process requires some technical expertise, but the project has a web-based USB installer for Pixel phones. It will probably offer similar resources when the Motorola devices arrive.

目前，摩托罗拉仅为廉价手机提供几年的更新支持，这对 GrapheneOS 来说是不够的。摩托罗拉尚未确认这些设备的发布时间表，但 GrapheneOS 应该会在设备发布时同步提供。安装过程需要一定的技术专长，但该项目目前为 Pixel 手机提供了基于网页的 USB 安装工具。当摩托罗拉设备上市时，它很可能会提供类似的资源。
