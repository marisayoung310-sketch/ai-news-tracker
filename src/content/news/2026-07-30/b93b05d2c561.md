# Google's "privacy-preserving" age verification system is coming to the Play Store
# 谷歌推出“隐私保护型”年龄验证系统，即将登陆 Play Store

Governments around the world are suddenly very keen on online age verification requirements. In some places, this takes the form of ID requirements to access adult content, but several US states have also focused on app stores. With these laws now going into effect, Google has announced an expansion of its beta Play Age Signals API, which it claims will allow developers to confirm user ages without impinging on privacy.

世界各地的政府突然对在线年龄验证要求表现出极大的兴趣。在某些地方，这表现为访问成人内容时需要提供身份证件，但美国几个州也将目光投向了应用商店。随着这些法律开始生效，谷歌宣布扩大其 Play Age Signals API 的测试范围，并声称该 API 将允许开发者在不侵犯隐私的情况下确认用户年龄。

Google’s system doesn’t require an ID or selfie verification—it’s connected to the company’s existing Family Link app. The idea is that parents will set age ranges for their kids’ managed accounts. For example, you might set a range like 16–17, allowing apps to tailor experiences and content for teenagers. Google notes that the ranges are dynamic and may change as young users get older. So a kid who’s 13 may be in the same app content bracket for a few years before hitting the next level.

谷歌的这套系统不需要身份证件或自拍验证，而是与公司现有的 Family Link 应用相连。其核心理念是让家长为孩子的受管账户设置年龄范围。例如，你可以设置 16-17 岁这样的范围，让应用为青少年量身定制体验和内容。谷歌指出，这些范围是动态的，会随着年轻用户的成长而变化。因此，一个 13 岁的孩子可能会在同一个应用内容区间停留几年，直到达到下一个年龄层级。

Parents have the option to set and share these ranges if they want that additional level of control over what their children can access in Google Play. However, it’s not mandatory for child accounts—it’s fully opt-in and can be turned off at any time.

如果家长希望对孩子在 Google Play 中可以访问的内容拥有额外的控制权，可以选择设置并共享这些年龄范围。不过，这对儿童账户而言并非强制性要求——该功能完全由用户自主选择，并可随时关闭。

Google began testing the Play Age Signals API late last year as it became apparent that multiple states were going to put the onus of age verification on app stores. The Computer & Communications Industry Association (CCIA), which lobbies on behalf of tech firms, has opposed these laws. However, the US Supreme Court recently paused a lower court injunction, allowing the Texas law to take effect. Louisiana and Utah also have similar laws going into effect.

谷歌于去年年底开始测试 Play Age Signals API，因为当时多个州已明确表示将把年龄验证的责任推给应用商店。代表科技公司进行游说的计算机与通信行业协会 (CCIA) 一直反对这些法律。然而，美国最高法院最近暂停了下级法院的禁令，允许德克萨斯州的法律生效。路易斯安那州和犹他州也有类似的法律正在生效。

The Play Store API was initially only available as a test in Brazil, but Google says it’s now beginning its global rollout. Australia and Canada will be the next regions to get the new API, and Google says developers in all countries, including the US, will have access to the Age Signals API by the end of 2026.

该 Play Store API 最初仅在巴西进行测试，但谷歌表示目前已开始全球推广。澳大利亚和加拿大将是下一批获得该新 API 的地区，谷歌称，包括美国在内的所有国家的开发者都将在 2026 年底前获得使用 Age Signals API 的权限。

This system won’t keep determined minors away from apps deemed too adult for them. Users must voluntarily share age data, and not all parents will bother setting this up. Kids can also just create alternative accounts and lie about their ages. Still, this should take care of Google’s compliance in any jurisdiction that requires store-level age verification for apps.

这套系统并不能阻止意志坚定的未成年人接触那些被认为过于成人化的应用。用户必须自愿共享年龄数据，而且并非所有家长都会费心去设置。孩子们也可以简单地创建替代账户并谎报年龄。尽管如此，这应该能解决谷歌在任何要求应用商店进行年龄验证的司法管辖区内的合规问题。

However, it’s up to developers to use the API. The Texas law does require that developers actively use age-gating features in app stores. The Play Store already has content ratings for apps, so it should be relatively simple for developers to translate that to reported age ranges. Google and other companies will probably continue fighting laws that require them to be app gatekeepers, but that may be a lost cause if courts don’t accept the First Amendment argument against them.

不过，是否使用该 API 取决于开发者。德克萨斯州的法律确实要求开发者在应用商店中积极使用年龄限制功能。Play Store 已经有了应用内容分级，因此开发者将其转化为报告的年龄范围应该相对简单。谷歌和其他公司可能会继续反对要求他们充当应用“守门人”的法律，但如果法院不接受他们提出的第一修正案抗辩，这可能是一场注定失败的斗争。
