### How To setup and run the project
### 如何设置并运行该项目

**FaceSwap is a Python program that will run on multiple Operating Systems including Windows, Linux, and MacOS. See INSTALL.md for full installation instructions. You will need a modern GPU with CUDA support for best performance. Many AMD GPUs are supported through ROCm (Linux).**
FaceSwap 是一个可以在包括 Windows、Linux 和 MacOS 在内的多种操作系统上运行的 Python 程序。请参阅 INSTALL.md 获取完整的安装说明。为了获得最佳性能，你需要一个支持 CUDA 的现代 GPU。许多 AMD GPU 通过 ROCm（Linux）提供支持。

**Overview: The project has multiple entry points. You will have to: Gather photos and/or videos, Extract faces from your raw photos, Train a model on the faces extracted from the photos/videos, Convert your sources with the model. Check out USAGE.md for more detailed instructions.**
概述：该项目有多个入口点。你需要：收集照片和/或视频，从原始照片中提取人脸，利用从照片/视频中提取的人脸训练模型，使用模型转换你的源素材。请查看 USAGE.md 获取更详细的说明。

**Extract: From your setup folder, run `python faceswap.py extract`. This will take photos from src folder and extract faces into extract folder.**
提取：在你的设置文件夹中，运行 `python faceswap.py extract`。这将从 src 文件夹中获取照片，并将提取的人脸存入 extract 文件夹。

**Train: From your setup folder, run `python faceswap.py train`. This will take photos from two folders containing pictures of both faces and train a model that will be saved inside the models folder.**
训练：在你的设置文件夹中，运行 `python faceswap.py train`。这将从包含两张人脸图片的文件夹中获取照片，并训练一个保存在 models 文件夹中的模型。

**Convert: From your setup folder, run `python faceswap.py convert`. This will take photos from original folder and apply new faces into modified folder.**
转换：在你的设置文件夹中，运行 `python faceswap.py convert`。这将从 original 文件夹中获取照片，并将新的人脸应用到 modified 文件夹中。

**GUI: Alternatively, you can run the GUI by running `python faceswap.py gui`.**
图形界面：或者，你可以通过运行 `python faceswap.py gui` 来启动图形界面。

**General notes: All of the scripts mentioned have -h/--help options with arguments that they will accept. You're smart, you can figure out how this works, right?! NB: there is a conversion tool for video. This can be accessed by running `python tools.py effmpeg -h`. Alternatively, you can use ffmpeg to convert video into photos, process images, and convert images back to the video. Some tips: Reusing existing models will train much faster.**
通用说明：上述所有脚本都有 -h/--help 选项，可以查看它们接受的参数。你很聪明，能弄明白它是怎么运作的，对吧？！注意：有一个用于视频的转换工具。可以通过运行 `python tools.py effmpeg -h` 来访问。或者，你可以使用 ffmpeg 将视频转换为照片，处理图像，然后再将图像转换回视频。一些提示：重用现有模型会使训练速度快得多。
